# Image2 故事板与 Seedance 视频生成迭代方案

更新时间：2026-07-04

## 结论

本项目应保留“角色定稿”步骤，不建议把角色三视图直接压缩进分镜生成步骤。

推荐主流程：

1. 剧本/角色卡生成。
2. 角色定稿：生成或上传角色参考后，统一产出角色身份板。
3. 场景卡定稿：为中长剧锁定主要场景、时代、光线、空间锚点和关键道具。
4. 分镜拆解：输出镜头表、首帧锚点、尾帧锚点、运镜、站位、声音和避免项。
5. Image2 生成故事板/首帧：带入角色身份板、场景卡和镜头提示词。
6. Seedance 图生视频：用合格首帧/关键帧 + 视频提示词生成短视频片段。
7. 质量检查、重生、选定、配音字幕、合成导出。

原因：

- 角色一致性是视频生成质量的上游约束。角色没锁定时，后续分镜图和视频都会反复漂移。
- 故事板适合做画面构图、站位、镜头意图和首帧锚定，不适合承载大量复杂细节。
- 中长剧更适合“角色卡 + 场景卡 + 镜头卡 + 关键帧”的路线，而不是一张巨大的密集故事板。
- 当前项目已有角色质量门槛，角色参考图未定稿时会阻止批量分镜图生成；该方向应继续强化。

## 对用户想法的产品化理解

用户提出的核心判断是正确的：

- 故事板不是单纯图片，它应该包含角色、场景、分镜、运镜、站位、画面锚点等生产信息。
- 但角色三视图不应该混在故事板里临时生成，而应该先成为“角色定稿资产”。
- 如果角色由 AI 生成，至少应产出三视图 + 大头照/表情特写，用来降低脸部漂移。
- 如果角色由用户上传，应先用视觉模型识别角色特征，再结合上传图和提示词生成统一身份板。
- 对 Seedance 来说，过密、过长、过多噪点的故事板会限制模型发挥，也会增加不一致风险。
- 小片段可以用故事板做得很惊艳；中长剧应优先保证角色和场景资产稳定，再按镜头生成。

## 角色定稿设计

### AI 生成角色

输入：

- 角色卡：姓名、身份、年龄感、五官、发型、体型、服装、气质、性格。
- 项目风格：真人短剧、国漫写实、电影感、竖屏/横屏等。
- 固定 seed、负面提示词、一致性等级。

输出：

- 角色身份板：正面全身、侧面/3/4 视图、背面、半身大头照。
- 锁定字段：脸型、发型、服装主色、配饰、体态、表情基准、负面提示词。
- 资产入库：`role` 或后续扩展为 `role_identity_board`。

关键规则：

- 同一角色只在定稿阶段描述外貌。
- 分镜和视频阶段只引用角色资产，不重新发明外貌。
- 换装、战损、童年、特殊状态要创建衍生角色资产。

### 用户上传角色图

输入：

- 用户上传的正面/半身/全身参考图。
- 用户补充的角色名称、身份、服装、禁忌点。

处理：

1. 视觉模型识别：脸型、发型、发色、年龄感、肤色、眼型、服装、配饰、风格、可辨识特征。
2. 生成结构化角色特征提示词。
3. 使用上传图作为参考图，结合提示词调用支持参考图的图片模型生成身份板。
4. 用户确认后锁定。

注意：

- 如果当前 Image2 通道不支持参考图输入，应走支持 image-to-image/reference image 的图片通道。
- 上传图不能只转成文字再重画，否则容易偏离；应尽量使用图像参考 + 文字特征双约束。

## 故事板设计

故事板在本项目中分两层：

1. 视觉故事板：Image2 生成的粗略分镜画面，用于看构图、站位、动作、情绪和首帧。
2. 导演故事板：系统用 HTML/SVG/结构化数据叠加准确文字、CAM、FOV、站位图、运镜、台词和声音。

不要让图像模型渲染长中文说明、完整分镜表、台词、CAM/FOV 标签。图像模型只负责画面，文字和站位图由系统确定性生成。

### 故事板生成输入

- 已确认剧本/分镜文本。
- 已锁定角色身份板。
- 场景卡：地点、时代、光线、空间锚点、关键道具、氛围。
- 镜头参数：景别、机位、焦距、运镜、站位、动作、情绪、台词/旁白、声音。
- 连续性锚点：首帧、尾帧、下一段交接。

### 故事板 Image2 提示词拆解

系统提示词应拆成这些稳定块：

1. 任务定位：生成可用于 AI 视频模型的导演分镜/首帧，不生成漫画成品。
2. 角色引用：使用指定角色身份板，保持脸、发型、服装、体态一致。
3. 场景引用：使用指定场景卡，保持地点、光线、道具和空间方向一致。
4. 镜头语言：景别、机位、焦距、FOV、运镜意图。
5. 站位调度：screen-left、center、screen-right；foreground、midground、background。
6. 动作与情绪：只写当前镜头一个主动作和一个情绪潜台词。
7. 首帧用途：画面必须适合作为图生视频首帧。
8. 避免项：无字幕、无水印、无标题字、无多余人物、无服装漂移、无脸部偏移、无肢体崩坏。

### 故事板局限

- 故事板适合短片段、关键动作、首帧锚定和审片，不适合把整集所有细节压到一张图。
- 密集故事板会产生视觉噪点，很多细节对 Seedance 无用，反而限制模型生成自然运动。
- 中长剧应按“场景 + 角色 + 镜头 + 视频段”拆开，不应把故事板当成唯一控制入口。

## 有了故事板后，视频生成还需要什么

Seedance 图生视频不只需要故事板，还需要以下生产包：

1. 合格首帧/关键帧图片：来自分镜图或故事板切片，画面清晰、角色稳定、无文字污染。
2. 视频提示词：镜头目标、人物位置、主动作、情绪、运镜、光线、道具状态。
3. 时长：优先 6-12 秒，单段不超过模型允许上限。
4. 画幅：9:16、16:9 或 1:1，和项目一致。
5. 首帧锚点：开场人物位置、身体朝向、景别、道具和情绪。
6. 尾帧锚点：结束姿势、视线、道具状态、运动终点。
7. 连续性交接：下一段必须继承的服装、站位、道具、情绪和空间方向。
8. 声音提示：角色语音、环境声、动作声效；不要让视频模型生成字幕。
9. 避免项：不换脸、不换衣服、不加字幕水印、不增加人物、不越轴、不改变道具归属。
10. 异步任务管理：提交任务、轮询状态、下载视频、入库、扣费/退费、失败重试。

## 开发落地建议

### V1：先做可用闭环

- 增加角色定稿工作流：
  - AI 生成角色身份板。
  - 上传角色图后视觉识别并生成身份板。
  - 用户锁定角色。
- 增加故事板提示词构建器：
  - 角色身份板 + 场景卡 + 镜头卡 -> Image2 分镜/首帧提示词。
- 增加视频提示词构建器：
  - 首帧 + 镜头卡 + 连续性锚点 -> Seedance 提示词。
- 前端在生产台中增加：
  - 角色定稿状态。
  - 故事板生成/重生。
  - 镜头首帧选定。
  - 图生视频按钮和任务状态。

### V2：提高中长剧稳定性

- 场景卡资产化：每个主场景生成/上传一张场景参考图。
- 镜头版本管理：同一镜头保留多张分镜图和多个视频草稿，用户选定最终版。
- 质量评测：角色一致性、画面匹配、视频可用性、字幕污染、运动崩坏。
- 批量策略：中长剧按场景/视频段生成，不一次性生成整集全部视觉资产。

### V3：成熟生产方案

- 灰度提示词版本：故事板系统提示词、角色定稿提示词、视频提示词都进入版本管理。
- 失败自动修复：根据失败原因自动选择重生角色、改提示词、换模型或降低时长。
- 成本策略：短片段高质量模型，中长剧先低成本草稿，选中后再高质量生成。
- 数据沉淀：把用户选定/废弃/重生原因转成评测数据集，用于后续提示词优化。

### 角色身份板

```text
你正在为 AI 短剧生产创建角色身份板。根据角色卡和参考图生成同一角色的多视图设定图。
必须保持同一张脸、同一发型、同一服装主色、同一身体比例和同一气质。
画面包含：正面全身、3/4 侧面、背面、半身大头照。
风格与项目一致，适合作为后续分镜图和图生视频的角色参考。
不要生成字幕、标题、水印、UI、额外人物或无关道具。
```

### 故事板/首帧

```text
你正在生成可供 AI 视频模型使用的导演分镜首帧。
使用给定角色身份板和场景卡，保持角色脸、发型、服装、体态、场景光线和空间方向一致。
只表现当前镜头的一个主动作和一个情绪状态。
明确画面站位：screen-left / center / screen-right，foreground / midground / background。

不要生成字幕、对白气泡、标题字、水印、表格、UI 标签或额外人物。
```

```text
主动作：[由系统填入]
声音：[角色语音/环境声/动作声效，由系统填入]

避免项：不要生成对白字幕、标题字、解释字、旁白字卡、水印；不要换脸、换装、增加人物、改变道具归属或越轴。
```

## 方案验证结论

可行，且与当前项目架构一致。当前项目已有：

- `Character`、`Asset`、`Storyboard` 数据结构。
- 图片 Provider、视频 Provider、任务队列和积分计费。
- 角色参考图未定稿时阻止批量分镜图的质量门槛。
- 导演分镜、Seedance 提示词、视频导出的基础模块。

下一步开发不应重写主流程，而应把“角色身份板 -> Image2 故事板/首帧 -> Seedance 图生视频”的提示词、状态、接口和前端操作补齐。
