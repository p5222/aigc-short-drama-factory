## 素材与导出的版本一致性

本轮发现相同镜头 ID 下更换首帧、尾帧或参考素材后，旧视频仍可能被视为当前结果。修复使用明确输入指纹和当前素材 ID，而非靠文件存在或时间戳推断。

- 媒体开始生成时，在项目生命周期锁内核验并持久保存输入指纹，同时冻结对应额度。异模态输入变更受保护；独立视频镜头允许并行。
- 视频恢复继续查询原远程任务，不重复提交未知结果的任务。完成时再次核验原始输入；过期结果保留为历史，不覆盖当前素材。
- 更换实际引用的角色、场景、镜头首帧或尾帧，会沿实际继承关系使相关旧结果失效；无关联镜头及其他项目不变。
- 历史素材保留文件 URL 和审核/反馈关联，当前镜头数量只统计当前素材，历史版本不使阶段虚假完成。
- 尾帧上传携带截取来源视频 URL；服务端拒绝旧播放器截图。浏览器等待 seek 有超时和可见错误，避免一直显示处理中。
- 全项目完成需全部有序镜头的有效 MP4 证明；单集或单镜导出不能使整项目变为已完成。
- 导出记录按原始输入返回 `sourceStatus`：`current`、`stale` 或 `unknown`。内容变更和未记录输入的旧导出保留下载并标历史，不计入当前配音、字幕或成片完成状态。
- 项目数据更新与手动刷新共用请求代次。旧导出、生产包以及原项目刷新晚到的成功或失败响应，不覆盖新版本，也不触发重复刷新或未处理的拒绝。

以上机制的真实数据库回归与最终完整测试结果在本次提交前统一记录；不以纯函数测试代替事务与并发验证。
