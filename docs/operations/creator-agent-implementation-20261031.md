## 实施约束

- 延续暖白、青绿与石墨灰视觉；不重做 Logo。
- 复用现有积分账本、报价模型约束、租约、素材版本和下游失效机制。
- 付费模型不可静默替换；重试、评测和分支费用受明确上限约束。
- 原稿是任务资料，不能修改工具权限和预算规则；数据、检索和复用按所有权隔离。
- 同一请求不同输入必须拒绝；供应商结果未知时先查询，不能声称外部“恰好一次”。
- 所有新增产品能力必须有实际调用路径，不把纯类型、说明文字或离线计划计作功能完成。
- 测试、研究、真实供应商效果和现金支付分别报告。用户访谈、长期留存和账单核验需要实际证据，不制造数据。
- 中间脚本、缓存、调试输出放在工作区外；交付与发布记录放 `outputs`。

## 已确认的接入点

- `apps/web/src/App.tsx`：路由、用户加载、手动 ProductTour。
- `apps/web/src/pages/WorkbenchPage.tsx`：首屏、续创与空状态。
- `apps/web/src/content/ContentWorkspace.tsx`：长篇开发与章节/剧本交接；默认 20,000 字、10 章。
- `apps/api/src/content/routes.ts`、`service.ts`：内容输入、生成、确认、交接。
- `apps/api/src/content/generationBilling.ts`：项目级操作租约和逐次模型计费；可复用但需保持锁顺序。
- `apps/api/src/production/episodeService.ts`：来源切分、分集生成和版本；目前固定 180 秒。
- `apps/api/src/prompts/catalog.ts`、`production.ts`：提示词定义、生效版本及兼容校验。
- `apps/api/src/billing/metering.ts`：真实 usage；生成无效 JSON 仍记录返回的费用依据。
- `apps/api/src/db/evaluation.ts`：质量中心和行为事件；部分规则评分只代表结构准备。
- `apps/api/prisma/schema.prisma`、`packages/shared/src/index.ts`：持久化和前后端契约。

## 验证与发布记录

实施中逐项补充实际命令、结果和限制。此记录初始创建时尚未进行产品代码修改、测试或部署。

### 后端第一阶段

- 新增用户引导偏好、作品意图与修订号、事实账本、执行计划与步骤持久化；短片生成采用独立提示词与 30/60 秒契约。
- 执行与原有积分冻结/结算共用操作租约：计划保存和实际执行分离、请求输入签名校验、最多两次调用、单次费用上限、取消后不启动下一次调用。
- 模型响应未知时停止自动重试，保留待核对状态；短片调用禁用底层协议/端点隐式重试，明确输出上限。
- 自动检查保留为结构/显式事实检查；作者确认另存版本。确认前不允许制作交接，确认后实际制作项目及分集目标时长沿用 30/60 秒。
- 事实保留来源与版本、故事时间、人物知情范围；锁定事实不能由模型覆盖。章节候选事实累积进入后续上下文；源文修订令候选/确认事实失效，作者锁定约束保留。
- 上下文清单区分必需资料、可选资料与估算；超预算阻止执行，不静默丢弃锁定约束。实际供应商 usage 从已有计量读取。
- 分集切分保留完整句子、原文前言与空白，邻接背景标明禁止挪用；未断句长文本不强行制造边界。
- 下一集续创保留拥有权、父作品版本与事实来源；时态设定转为候选。制作交接仅复用同风格、相符角色设定的合格角色/场景/道具图，保留来源资产版本，不复制旧分镜/视频。
- 已通过 API 类型检查、13 项既有内容/分集单元测试和 4 项新增记忆/预算/质量契约测试。
- 第一轮真实隔离 PostgreSQL 回归：既有内容编辑、账本租约与制作交接通过；新执行测试发现 JSONB 字段顺序影响“无进展”比较，已改为规范化签名后重跑。供应商响应为隔离夹具，不属于真实质量或账单证据。
- 修复后 `creatorIntegration.test.ts` 真实数据库 9 项全部通过（8 个子场景）；包含短片确认重放、两次修订上限与无进展停止、未知结果阻断、取消/过期、锁定冲突、拥有权与费用、用户引导隔离、下一集事实和素材来源。23 项模型身份/生成基础/预算/记忆/切分单元检查通过。

以上为后端实现进度；首作界面、动态预览、成果成本口径、完整回归和生产发布尚未完成，不能按本阶段标记整体验收。

### 产品接入与第二阶段验证

- A1–A3：工作台首访起步区按账户状态展示，支持跳过和恢复、灵感/已有材料/示例分流。短片创作独立于长篇流程；意图、目标时长、模型选择、报价、持久执行、作者编辑确认、制作交接全部接入。
- B1–B3：短片和长篇均提供故事设定编辑入口，显示来源版本、故事时间与知情者；本步资料清单、保守估算与供应商实际用量分别显示。草稿按账户和作品保存在标签页会话中，保留离开和版本冲突保护。
- C1–C3：执行步骤、恢复、取消和结果未知核对有实际页面入口。新增发现并修复一次调用上限的结束状态问题；规范化 JSONB 顺序避免误判无进展及前端误判意图变更。
- D1：分镜阶段可以按镜头时长播放现有首帧、拖动预览进度，清楚标明静帧预览无真实运动/配音。视频生成现按勾选镜头范围提交。
- D2/E2：成片评价绑定输出指纹，保留反馈版本和历史；累计关联故事与制作任务，含失败/修复，未知成本不显示为零。可用性必须由作者选择，按已确认可用成片计算每秒积分。供应商成本及账单核验单列，历史复用素材成本不重复分摊。
- E1：续集复用数据库回归发现旧“场景一”标题可能误识别角色，已修复中文场景编号，并要求场景/道具名称和描述一致才复用。
- 运营总览新增最近 30 天首作路径去重人数、首次确认中位时间与执行异常观察；明确不同阶段人数不可直接相除作为转化率。
- 第二轮真实隔离数据库：创作执行及续集 10 项、交接提取 3 项通过；成果反馈与成本聚合通过，旧导出快照 4 项通过。供应商响应仍为测试夹具。
- 首作与视频相关浏览器 30 项通过，覆盖桌面/手机、深浅主题、跳过恢复、保存/报价/审阅/交接、未知结果、冲突草稿、剪辑回归、分镜预览和成片反馈。视觉截图已检查；此后又做了保存意图折叠、模型切换入口及运营观察接入，需在全量回归中复验。
- 新增项目事件、成片评价和既有尾帧路由统一置于 API 登录验证后；服务层仍校验拥有权。后续完整真实 HTTP 回归须验证这些路由匿名/跨账户访问。
