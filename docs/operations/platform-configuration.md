# 漫角后台配置手册

这套框架支持在后台配置模型渠道、默认模型路由、注册邮件与微信 Native 支付。接入下表中的协议时，不需要修改代码；模型权限、账户余额、地域和接口版本仍须与供应商控制台一致。

## 一次配置的顺序

1. 用具有配置管理权限的管理员进入 **后台 → 模型渠道**。
2. 新建渠道，填写名称、唯一渠道 ID、用途、接口协议、接口根地址、API Key 和精确模型 ID。渠道 ID 可自定义，不再要求使用内置名称。
3. 选择首选模型；初次接入建议固定一个已经确认可用的模型。视频填写分辨率，配音填写默认音色和语言。
4. 在 **模型定价** 核对每个模型的价格。文本按次、图片按张、视频按秒、配音按 Unicode 字符；同一渠道和模型只保留一条生效价格。图片尺寸/质量、视频时长/分辨率还会影响实际报价。
5. 进入 **平台配置 → 创作默认渠道**，分别选择文本、图片、视频、配音渠道并保存。
6. 查看平台配置页的配置检查清单，逐项补齐，再使用各渠道的测试按钮。
7. 建一个短片，按“确认剧本 → 角色参考图 → 分镜 → 首帧 → 视频 → 配音和 MP4 导出”完成一次小范围实测。

配置检查只说明字段、协议、价格和本地服务是否齐全。只有真实生成、文件解码和供应商账单核对，才能证明所填 API 在自己的账户中可用。

## 支持的接口协议

| 用途 | 后台协议 | 根地址示例 | 说明 |
| --- | --- | --- | --- |
| 文本 | OpenAI Chat Completions | `https://api.openai.com/v1` | 使用 `/chat/completions`；可接兼容服务 |
| 文本 | OpenAI Responses | `https://api.openai.com/v1` | 使用 `/responses`；不因失败自动改投 Chat |
| 文本 | Gemini GenerateContent | `https://generativelanguage.googleapis.com/v1beta` | 使用 GenerateContent 格式 |
| 图片 | OpenAI Images | `https://api.openai.com/v1` | 文生图用 generations，参考图编辑用 multipart edits |
| 图片 | 通义万相 / Qwen Image | `https://dashscope.aliyuncs.com/api/v1` | 使用百炼原生接口；模型必须支持所需参考图数量 |
| 图片 | 火山方舟 Seedream | `https://ark.cn-beijing.volces.com/api/v3` | 参考图使用 JSON `image` 字段 |
| 图片 | Gemini Interactions Image | `https://generativelanguage.googleapis.com/v1beta` | 需要支持 Interactions 图像输出的模型及账户权限 |
| 视频 | 通义万相异步视频 | `https://dashscope.aliyuncs.com/api/v1` | 首帧生成、任务提交与原任务查询 |
| 视频 | 火山方舟 Seedance 异步视频 | `https://ark.cn-beijing.volces.com/api/v3` | 精确模型 ID/接入点 ID 以控制台为准 |
| 配音 | DashScope Qwen TTS | `https://dashscope.aliyuncs.com/api/v1` | 填写模型支持的音色和语言，返回 WAV 音频 |

根地址填到表中的 API 根路径，不重复追加 `/chat/completions` 等操作路径。不要把 Key 写进 URL。其他区域、业务空间或中转商应填写其提供的对应根地址。

“兼容 OpenAI”不代表该服务支持所有 OpenAI 接口。特别是 Qwen 的兼容文生图扩展与 multipart 图片编辑不是同一种协议：需要 Qwen 参考图编辑时请选择百炼原生图片协议。供应商不支持参考图时会明确失败，不会悄悄丢掉参考图。

Sora、Runway、ComfyUI 等未接入生产生成链路的插件会显示尚未集成；填写 Key 不会让它们变为可用。接入表格以外的协议仍需要开发适配器。

## 保存、生效与恢复

- 后台保存的 Key、根地址和连接参数优先于该渠道的服务器默认值，下次请求生效，不需要重启。环境配置本身变更时仍需要重新创建服务容器。
- 保留密钥不会覆盖原值；替换用于换新 Key；清除后台覆盖会恢复该渠道的服务器配置。自定义渠道没有对应环境默认值时，清除后即为未配置。
- 密钥不回显；后台只展示配置状态和有限预览。页面保存失败会保留草稿；其他管理员已修改同一配置时，会拒绝覆盖并提示刷新。
- 默认文本、图片和视频用于新作品。短剧本首次进入制作也会保存图片和视频默认渠道；后续改默认不覆盖已有作品。
- 配音默认用于导出时的新报价。角色单独指定的音色优先于渠道默认音色；修改配音模型、音色、语言或台词后会重新报价。重复导出会复用相同内容的已付费音轨。
- 已提交但仍生成中的视频会查询原任务。换了渠道地址时，应先恢复原地址处理旧任务，不要重复提交未知结果的任务。

## 注册邮件

在 **平台配置 → 注册邮件** 填写 QQ 发信邮箱和 SMTP 授权码，通常使用 `smtp.qq.com`、465 端口、隐式 TLS。使用 587 端口时关闭隐式 TLS，服务仍强制 STARTTLS。

“测试 SMTP”只检查已保存配置的连接与认证，不会发送邮件。保存后使用自己的 QQ 邮箱在注册页申请验证码，确认收件和验证码校验。已有 QQ 邮箱注册功能此前已完成真实投递验证，换邮箱或授权码后仍需重测新配置。

手机号为注册资料，不需要配置短信 API。邮箱验证码有效期 10 分钟，重发间隔 60 秒。

## 微信 Native 支付

在 **平台配置 → 微信 Native 支付** 填写 AppID、商户号、商户证书序列号、商户私钥、API v3 密钥、微信支付公钥 JSON，以及公开 HTTPS 回调地址：

`https://manjiao.cloud/api/billing/wechat/notify`

可先保存配置并保持“开放新订单收款”关闭。配置测试检查密钥格式和本地签名，不创建交易。正式启用后，需要自己完成一次真实下单、扫码付款、回调到账与对账验收。

存在待确认微信订单时，系统会阻止更换商户核心配置，以免旧订单无法处理；单独暂停新收款不影响旧订单回调与对账。会员仍按月手动续费，不自动扣款，会员身份不授予后台管理权限。

## 部署与恢复

服务器需要数据库、Redis、持久化素材目录及可用 FFmpeg。生产镜像已包含 FFmpeg；公开域名和素材访问配置由部署环境管理，不属于模型 Key。

`PLATFORM_SETTINGS_KEY` 是服务器用于加密后台秘密的根密钥，首次部署时只初始化一次。以后发布必须保留原值，并随私密环境备份保存；单独恢复数据库而丢失这个根密钥，会导致已加密 Key 无法解密。根密钥、SMTP 授权码、商户私钥和 API Key 均不应进入 Git、前端或公开交付文件。

旧渠道配置保持兼容读取，新增或更新的秘密会加密保存。回滚到尚不支持加密配置的旧版本时，需要恢复与旧版本匹配的数据库及私密环境备份；只切换旧镜像不足以保证新保存的渠道 Key 可用。

## 接入后的验收范围

建议先用 30 秒短片验证单个模型组合。确认本站积分报价、供应商真实扣款、生成画面和声音质量、视频连贯性以及最终 MP4 可播放，再扩大调用规模。

框架回归使用真实数据库、计费事务、文件存储和 FFmpeg，供应商响应使用隔离夹具；它能证明配置与业务链路的连接，不能代替你的供应商账户授权、真实样片质量和现金支付验收。
