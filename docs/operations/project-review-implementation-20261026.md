## 实施约束

- 不新增赠送积分、自动现金退款、自动代扣、生产样片调用或真实支付操作。
- 不改写现有幂等、冻结结算、删除审计、素材来源和工单版本保护。
- 本轮新增统计使用既有表，无数据库结构变更；仍执行安全 schema 检查和发布前后财务核对。
- 工作台样本与全量数量分别返回；无新字段的旧响应显示未确认，不从最近列表假设全量。
- 支持诊断仅使用公开任务字段，不带原稿、上游凭据、原始请求、私有访问配置。复制由用户点击触发。
- 定时巡检只写本机日志，不自动发消息；外部接收渠道和持续异地存储列为外部条件。
- 临时脚本、调试缓存和浏览器结果保存在工作区外；正式方案、验收记录和必要截图作为交付物留在项目内。
