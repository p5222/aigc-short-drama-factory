## 产品与验收目标

覆盖 `manjiao.cloud` 前台、`/admin` 运营后台，以及跨电脑 GitHub 拉取、分支、提交、推送、腾讯云发布与回滚工具。沿用现有漫角视觉，跑通登录 → 内容策划/导入 → 剧本分集 → 角色/场景 → 分镜 → 图片 → 视频 → 配音字幕 → 按选集和顺序导出真实 MP4 → 提交作品 → 后台审核 → 公开展示。

付费动作必须可报价、按任务冻结及结算、并发安全，失败可恢复。后台操作必须有权限、错误反馈和可追溯记录。未实现或未配置的服务不能假成功。
