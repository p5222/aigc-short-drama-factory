## 已实现的流程

| 模块 | 行为与证据 |
| --- | --- |
| 公告 | 后台创建、编辑、停用可在工作台真实展示或隐藏，保留置顶及类型信息，手机可展开正文。排期按北京时间解释，结束日期包含当日最后一毫秒；保存未修改的日期不改变原精确时间。倒置日期在前后端均拒绝，部分更新在数据库行锁内合并校验。跨开始/结束时间时仅更新状态，筛选成员保持至显式筛选或服务器列表更新，防止编辑行自动卸载丢失草稿。 |
| 设置与账户 | 主题按钮实际切换并持久化，刷新后仍选中；账户、安全、任务、账本与帮助入口可进入对应页面。删除无功能的模型选择控件和“1 积分≈1 元”表达，购买以实际套餐和报价为准。 |
| 密码恢复说明 | 登录页不再声称绑定邮箱后可以自助找回。忘记密码应向所属平台管理员申请重置；个人页修改需已登录并提供当前密码。暂无匿名邮件找回，不编造支持邮箱或即时客服入口。 |
| 用户工单 | 新建、分页列表、详情、补充和关闭使用真实接口；服务器确认后显示成功。按账号保存会话草稿，失败保留输入。冲突要求刷新后复核再提交，关闭后不再允许追加。 |
| 后台工单 | 独立支持工单导航，按状态筛选、打开详情和回复；客服回复使工单变为已回复，用户补充使其回到待处理，关闭为终态。 |
| 工单一致性 | 创建、回复、关闭使用持久幂等请求；重试同请求返回原结果，变更载荷冲突。版本号与行锁防止覆盖并发回复，消息仅追加。跨账号请求返回 404，普通账号不能访问后台，作者角色由服务端决定，审计不保存正文。 |

1. 独立普通账号完成图形验证码后，补注册/登录、退出与工单的浏览器证据；另验证忘记密码时管理员重置的实际协作路径。
2. 最低可用套餐真实购买、外部发码、兑换到账与重复兑换拒绝，核对店铺订单和平台流水。需要店铺库存、付款及费用授权，本机机制测试不能代替真实履约。
3. 按[真实供应商样片方案](./real-provider-acceptance.md)验证实际 AI 成片质量和供应商现金账单；尚无费用授权时不发起付费调用。
4. 第二台个人电脑按[跨设备指南](./github-and-multi-device-deployment.md)接续分支、AI 修改、推送和发布；第二个实际项目需要提供独立仓库及部署目标。现有隔离多项目测试不能代替指定设备与项目的实操。
5. 懒加载资源失败和原生离开确认的浏览器故障注入仍需留证；已通过的正常流程和单元防护不算此项通过。
