# 后台模块与交互状态清单

审计日期：2026-09-12。代码基线：`83d8f95d` 及审计时共享工作区。初始只读范围为 `AdminPage.tsx`、`src/admin/`、支持工单后台入口和对应样式。随后根代理授权实施后台重设计，实际修改与验证见文末“本轮实施交付”。全过程未运行生产写操作、未点击收费模型测试。

这是供整体重设计使用的**代码与交互状态清单**，不是新的浏览器视觉验收。页面实际首屏比例、滚动遮挡、颜色对比和手机触控需要根代理按相同页面/尺寸截图核对。本文“演示感”指能够从代码确认的假分页、重复装饰指标、技术占位内容与操作结构，不据此声称实际截图不合格。

## 现有结构及应保留的机制

当前有 13 个顶层模块：运营总览、用户管理、平台公告、支持工单、创作现场管理、创作质量中心、提示词评分、兑换码、套餐会员、订阅会员、模型路由、价格策略、操作记录。质量中心又包含 6 个工作区，实验评测有 5 个标签，事件与 VOC 有 4 个标签。

已有可复用组件，不必重写已经验证的事务与流程：

- `AdminShell.tsx`：桌面导航、820px 以下导航弹层、焦点约束、Escape 关闭及焦点返回；当前项使用 `aria-current`。
- `AdminTablePage.tsx`：语义表格、真实加载/错误/空态接口、可选分页；整行可用 Enter/Space 打开详情，行内控件不会误触整行。
- `AdminMasterDetail.tsx` / `useAdminDialog.ts`：详情侧栏、滚动锁、焦点循环、提交期间禁止关闭；可承载统一详情/编辑布局。
- `adminActionModel.ts`：同步防重锁、失败返回值、成功后刷新失败的专门提示、批量遇失败停止。根 `fieldset` 在共享操作期间禁用，不能误报“所有按钮均无防重”。
- 审核已有 `expectedUpdatedAt` 冲突、必填驳回原因、保存/审核期间禁用；工单已有真实分页、草稿、版本冲突及终态；公告已按**服务器保存状态**显示生效标记，并另示“未保存”。这些应作为新组件的行为基线。

下面“共享反馈”指 `AdminActionContext` / 页面顶部成功或错误提示，**不等于该行附近已有反馈**；“共享读取”指父级 `App` 加载数据，此模块不接收自己的 loading/error。无写入的只读模块，成功与提交禁用标为“不适用”，不要求制造一个保存按钮。

## 明确问题与实施优先级

### P1：数据范围和状态真实性先于皮肤调整

1. **移除假分页并修复可达范围。** `AdminPage:5274` 的 `TableFooter` 固定显示“1至min(total,20)”，两个翻页永远 disabled，中间“1”无动作。公告/帮助/套餐/渠道/价格实际渲染全量；兑换码实际最多50，批次预览最多20；0项仍出现“1至0”。应该按模块使用真实分页，或准确写“共N项”并去掉分页。兑换码已有“前50条，请搜索”的说明，不能称为完全静默截断，但用户不能逐页检查未记住卡密的后续记录。
2. **保存状态与草稿状态分开。** `HelpArticleRow:2668`、`PlanRow:4618`、`ProviderRow:4796`、`PriceRow:5162` 从 `draft.enabled` 渲染生效色块，切换后未保存也变为启用/展示中。统一复用公告的“已保存状态 + 未保存变更”模式；列表只显示持久状态，编辑区标待启用/待停用，并明确保存按钮。
3. **筛选必须与分页使用同一数据范围。** `FeedbackOpsSection:2025` 服务端查询只接关键词/阶段/状态；`:2040` 又对当前50条按可用性/优先级筛选。高优先级问题可能在别页，当前页空不能说明没有。把这些筛选传服务端并同步total，或明确“当前页筛选”且不能用它做全库待办统计。质量快照首读/失败时也不能用0%冒充已测值（`:820/:832`）。
4. **所有编辑离开路径统一保护。** `AdminMasterDetail`、`AdminModal` 只根据 busy 阻止关闭；根模块条件挂载和各视图切换没有 dirty 保护。套餐/价格仅初始化draft，帮助/公告又会按updatedAt重置，策略不一致。新组件应明确“保存并关闭 / 放弃修改 / 继续编辑”，保留409或网络异常输入；先用长公告、调价、用户详情和提示词切阶段做本机验证。

### P2：使操作密度和命名服务实际任务

5. **列表负责查找，编辑器按需打开。** 公告/帮助完整正文、套餐9列输入、价格整批输入和渠道高级配置同时出现，造成“每项都是表单”的维护成本。保留一个主列表、一个当前对象编辑器、一条动作结果；把现有用户/审核/审计的 MasterDetail 模式扩展给配置模块。禁止为了外观去掉字段、批次范围或来源版本。
6. **收拢重复导航与弱指标。** 当前外层13模块、内层rail、质量多级tabs重复占空间；多页固定4彩色指标卡，但“模板输出JSON”“所有订阅月费之和”“不同单位模型平均积分/成本合计”（`:3848`）不能帮助决定下一步。日常运营优先露用户/支持/审核；充值套餐与订阅历史分开；质量操作与生产配置成组。配置页优先显示有效数量、缺配置、待处理，不强行四卡。
