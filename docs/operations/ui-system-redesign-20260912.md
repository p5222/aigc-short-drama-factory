## 设计依据与范围

依据现有漫角前台、管理后台、生产工作区代码和实际浏览器截图，延续漫角名称、青绿色主色与现有内容素材。用户目标是成熟可持续使用的创作和运营工具。旧的生产台设计文档只作为历史背景，不照搬旧营销卡片或未实现的工具。

前台完整清单见 [creator-ui-inventory-20260912.md](./creator-ui-inventory-20260912.md)，后台 13 个顶层模块及子视图见 [admin-ui-inventory-20260912.md](./admin-ui-inventory-20260912.md)，样式来源与所有权见 [ui-style-architecture-20260912.md](./ui-style-architecture-20260912.md)。这些清单中的代码发现与本轮视觉截图证据分别记录，不混为已通过。

## 统一设计决策

- 工作空间：桌面侧栏 232px、顶部 64px，页面最大宽度 1440px；手机改为完整抽屉导航，关闭不可聚焦、打开锁背景、键盘循环、关闭返回触发按钮。避免横向滚动的整排主导航挤占首屏。
- 版式：标题 26px（手机 23px），正文 13–14px、辅助 12px。统一 4/8/12/16/24/32 间距、7px 控件和 10px 面板圆角，弱化装饰阴影、重渐变、超粗标题和重复指标。
- 主题：浅色中性灰底与白色表面；深色中性灰黑表面。所有正文、边框、主操作、危险和选中状态使用 `--ds-*` 语义变量，去除旧暗色紫蓝主按钮与固定白色抽屉。
- 层级：每页清晰标题、说明和主要操作；作品和下一步动作优先于公告/技术说明。工作台公告移到辅助栏，任务页不再用多排零值卡片遮住真实任务。
- 表单：按任务分组，显式保存/取消/未保存状态，失败保留输入；尚未保存的开关不冒充线上已生效。只显示实际支持的功能。
- 反馈：统一 PageHeader、StatePanel、InlineNotice、Dialog 和 ConfirmDialog。覆盖加载、空列表、无筛选结果、网络/权限错误、成功、禁用原因、脏草稿和危险确认。
- 弹层：共同实现标题描述关联、初始焦点、Tab 循环、Escape、背景 inert、滚动锁和关闭还焦点；保存中不意外关闭。
- 数据：不伪造线上指标、成功状态、用户内容或 AI 生成结果；真实付费生成和购买不属于本轮 UI 回归授权。

## 验收标准

每个页面至少有正常或空数据截图；关键交互覆盖输入、筛选、打开/关闭详情、保存/取消、错误恢复和禁用原因。相同视口、主题、账号和数据对比改前/改后；深浅主题与手机分别检查，不用桌面截图代替手机证明。无付费的失败场景优先在隔离数据和本机网络故障下验证，无法访问的真实外部条件明确标记。

功能回归按实际改动运行；完整 Web 单元、类型检查与生产构建在所有代理冻结后统一执行。新分支尚未 CI、合并或部署，不能借用上一版上线证明。
