产品定位与评审结论

核心用户是漫剧创作者，核心任务是把灵感、小说或剧本转换为可预览、可下载、可审核发布的作品。管理员负责账号、模型、积分、作品审核与支持。用户点击新建、续创或处理失败任务触发流程；完成条件是目标范围的当前成片可播放下载，发布作品经审核后可以匿名播放。

判断：项目已有真实生成、积分结算、微信支付代码、版本保护、工单和恢复工具。当前最值得投入的方向是补全行动入口、修复状态误导、保证账号初始化一致、将回归固化到 CI，并把运行监测和商业验收条件写清。

当前生产基线已通过公开 readiness、桌面与手机入口检查，以及真实 PostgreSQL/Redis 集成验证。微信支付保持关闭；付费供应商输出质量与现金交易尚未完成真实验收。最近发布证据见 69b1387 发布记录。

每个付费动作遵循“读取真实报价 → 用户确认上限 → 冻结积分 → 持久任务 → 成功结算 / 失败解冻”。内容变更后，下游素材和成片按输入快照标记历史。网络丢失响应时先核对原请求，不创建第二次收费动作。

本轮完整需求

FR-01 · P0 · 账号一致性

注册后立即拥有可用账户

用户提交合法邮箱、密码和可选手机号后，账号与初始积分账户同时保存。任一持久化步骤失败时两者均不创建。初始积分仍由现有环境配置决定，不新增赠送额度。并发同邮箱或手机号注册只能成功一次，其余返回明确冲突；不返回数据库内部错误。会话签发失败时账号可通过正常登录恢复。

正常状态：未注册 → 账号和积分账户已创建 → 已登录。失败状态：输入保留，可核对后重试；跨账号信息不返回。验收涵盖并发重复、账户关系存在及初始金额一致。

FR-02 · P0 · 创作者行动中心

全量待办，不遗漏早期任务

工作台显示该账号所有项目的待确认数量、全部排队或运行任务数量、失败任务数量。最近作品和任务仍作为续创区域；待办样本单独读取，不受最近列表截断影响。数量为零时明确显示没有事项，未读取时显示待确认，不用最近样本替代全量数量。失败入口进入任务队列，待确认入口打开实际待确认作品，统计时间可见。

待确认 9 项 · 生成中 12 项 · 失败 3 项。最近 6 个作品不影响全量数量。

FR-03 · P1 · 运营待办

总览直接提示需要处理的事项

管理员看到待回复工单、待审核作品、待确认真实订单及活动任务数量。工单默认进入待处理筛选，作品进入审核模块。待确认订单仅计真实通道未完成确认的订单，不等同付款成功，不提供人工“标记已付”捷径。所有数量由服务器提供，并带查询时间；读取失败不显示 0。

待处理工单 4 条 · 待审核作品 2 条。点击后进入工单列表的“待处理”状态。

订单本轮只提供真实数量和核对指引，现金及会员权益继续经签名回调 / 主动查单事务确认。

FR-04 · P0 · 失败恢复与支持

按任务权限恢复，并保留正确编号

可重试任务显示重试入口；禁止直接重试时提示回到所属作品核对结果与渠道，结果不明时先刷新并联系支持。平台任务 ID 与内部队列标识分开显示，客服以平台 ID 定位。用户可查看并复制不含原稿、密钥和原始请求的诊断摘要，再进入帮助中心提交工单；复制失败时仍能手动选择文本，已有工单草稿不被覆盖。

此任务不能从队列直接重试。回到作品核对结果与渠道，或复制平台任务编号提交工单。

FR-05 · P0 · 交付检查

当前集是否可以交付，一眼可见

成片页列出当前集的视频完整性、配音、字幕、当前 MP4 四个检查项。未生成配音或字幕是可解释状态，导出仍按真实报价和对白需要决定，不强制增加付费步骤。缺少视频时导出按钮不可用，并给出缺失数量；“成功”但没有有效视频地址视为待补齐，不能显示生成中。当前成片由服务器输入快照确认；历史和未知版本不能冒充当前交付。

视频 2/3：还有 1 个镜头需补齐。配音、字幕及成片分别检查，不能提前宣称交付完成。

FR-06 · P0 · 质量门槛

界面回归成为每次发布的必经阶段

所有现有浏览器套件和本轮新用例在 CI 执行桌面、手机两种视口，覆盖新建/恢复、后台操作、主题、任务恢复和交付检查。CI 失败阻止发布，并保留截图、trace 与报告。用例明确标记隔离 UI 夹具，不把其结果当作数据库、供应商或真实付款验收；真实数据库和生产镜像回归继续执行。

FR-07 · P1 · 运行监测

检查有时限，失败有记录

提供只读监测命令，检查公开 readiness 与预期 revision，另在服务器检查完整备份标记、校验文件是否存在及最新备份时间。请求超时、异常 JSON、非就绪、版本不符和备份过期均返回失败状态。仅记录检查结论、时间和生产版本，不输出密钥、账号或剧本；不得触发生成、支付或向第三方自动发送消息。

巡检频率、备份新鲜度阈值在部署配置中明确；外部通知接收人和长期异地存储属于待配置条件。本地失败记录不能冒充外部告警送达，也不等同完整恢复演练。

共用权限与状态规则

对象规则
账号 / 数据创作者只查看本人项目、任务、积分和工单；管理员接口继续校验 admin 权限。停用账号旧会话失效。
任务排队 → 运行 → 成功 / 失败 / 取消。以服务器 retryable、cancelable 为准；未知供应商结果先核对，不由前端推导可重试。
积分 / 现金冻结与结算保留幂等事务；失败退回未消耗冻结额度。解冻不代表现金退款。充值实收不等于已确认消耗收入。
素材 / 成片当前、历史、未知来源分开；只核对用户选择的集数和顺序。单集完成不把整部项目提前标记完成。
工单 / 审核工单消息只追加，版本冲突刷新后复核，关闭后不追加；审核使用实际来源与版本，驳回重提保留原 ID 和意见。
发布验收通过才同步 GitHub 与腾讯云；对比 GitHub main、服务器 main、deployed 和公开 revision，备份副本校验后留存。
