漫角 Studio 项目细化与本批迭代 PRD

日期：2026-10-27。依据：全项目审查报告和用户已授权的全量审查任务。正文定义用户行为；技术及验证见执行矩阵。本批直接实施有证据的可回滚改进；新增商业规则需依据真实配置与运营决定。

1. 目标与统一规则

用户能够在登录过期后恢复工作，明确区分当前内容与历史版本，在生成仍运行时避免删除正在交付的内容，并准确理解任务费用状态。公开页面中文、英文内容完整一致，沿用暖白、青绿设计。

角色：访客只能访问公开资源；创作者只能管理本人内容、任务、积分及工单；管理员沿用现有权限。章节是一份内容项目内同章的版本记录；任务状态refunded表示冻结积分释放；充值订单refunded仍表示订单退款。可用积分=总余额−冻结积分。纯编辑、翻译与元数据改进无供应商调用或积分费用。

2. 本批功能要求

FR01 会话过期和恢复

触发：当前会话请求401且确认不是旧token的迟到响应。界面必须退出已失效登录态并显示重新登录，即使浏览器禁止读取或写入sessionStorage。恢复的用户ID、页面、项目ID在当前页面内存中有后备，存储可用时保留标签页恢复。

同一用户重新登录可回原页面；不同用户必须重置所有账户数据和草稿。恢复信息不可用时安全回工作台并重读本人数据。新用户不得短暂看到旧账号项目、余额、订单或后台数据。恢复元数据不是权限凭证，项目仍由API验证归属。正常退出也必须容忍存储异常。网络失败与401分开，不清除有效token。

验收：存储禁用的401和重新登录、正常存储的同用户恢复、不同账号加读取失败、旧请求迟到、退出。测试只能证明本地会话行为，不冒充生产登录验收。

FR02 章节编辑保留版本

入口：正文创作→编辑本章。前置：本人项目已有正文，当前没有该项目生成操作。保存携带打开编辑时的章节记录ID；基准已变化时返回409，保留用户输入并提示刷新核对。新版前端必须提交基准，兼容旧客户端的无基准请求仍串行并追加版本，不能宣称旧客户端已获得冲突检测。

成功后产生新记录和递增版本号，旧记录及正文保留。版本列表更新；界面说明“另存新版本”，不能再说覆盖当前版本。纯重复保存不新增版本、调用供应商或扣积分。后续章节生成的交接必须反映手改正文，不能保留旧正文的交接结论。制作集沿用已有stale标记；用户需要重新生成剧本和同步制作，已有MP4不自动冒充新内容。

保存完成但版本列表重读失败时保留成功事实，提示版本列表暂未刷新，不能让用户重复保存。409后不得自动替用户覆盖新版本或丢弃草稿。基准使用不透明记录ID，未来协作可扩展，但本次不建立多人协同业务。

验收：旧正文保留、新ID与版本、并发保存仅一方成功、重试相同输入不重复、跨账号拒绝、活动生成拒绝、下游stale、手改交接、UI冲突草稿与版本刷新失败。

FR03 内容项目删除保护

入口：我的作品/内容项目列表→删除确认。本人归属不存在返回404；存在任何活动内容生成任务返回409，作品、正文和账务保持不变。删除与同项目新生成争用同一生命周期保护，不允许检查完成后新任务穿过再删除。

拒绝说明先等待任务结束或到队列核对。不自动取消收费供应商任务，不把异常心跳当作无费用成功。成功删除保留现有独立账务/任务历史。项目回收站不在本批；仍沿用现有明确删除确认。

验收：running/pending操作、孤立活动billable子任务、删除与生成竞争、跨用户、正常已结束项目删除、拒绝后UI保留项目。无生产数据删除测试。

FR04 任务积分状态及帮助

队列、抽屉、制作工作区、进度提示把任务refunded显示为“已解冻”，解释“冻结积分已释放，不代表现金退款”。失败原因及人工核对入口仍保留，不能把所有失败任务都说成已退款。流水类型refund为“释放冻结”，帮助描述结算后“释放多余冻结额度”。

充值订单refunded仍显示“已退款”；不修改后端枚举、历史流水、充值记录或现金退款规则。中英文登录只提示已支持的手机号/邮箱，昵称错误提示使用昵称。

验收：退款任务筛选与详情、历史终态、帮助内容、订单标签不变；纯文案不另造复述实现的单元测试。

FR05 公开页面语言及站点摘要

创作现场分类、精选标签、卡片默认说明、空封面入口、分页、预览关闭/背景及播放失败按当前语言显示。传给服务端的分类仍为既有中文key，搜索、页码和已审核公开规则不变。

静态首页description只描述已有的故事、剧本、分镜、图像、视频、配音字幕与导出能力。不承诺免费生成、全部模型可用、真实利润或自动商业成功。不新增图片素材或外部页面依赖。

验收：英文分类请求key、分页、Esc关闭/焦点、视频错误、360/390/768/1024/1440/1920代表布局、浅深主题及文档无横向溢出。后台保持当前设计体系，不声称本次1:1复刻sub2API。
