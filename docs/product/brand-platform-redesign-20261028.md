# 漫角品牌与全平台视觉迭代

本轮响应 2026-10-28 的八项要求，范围覆盖品牌、创作者各页、生产工作区、模型中心、个人中心、充值与后台共用设计系统。目标是让导航、内容层级和状态在全站保持一致，并提升长时间创作的阅读与操作体验。

## 设计方向

- 品牌：原创几何矢量标志，围绕“漫角”的折角与故事画面表达，形成可辨认的小尺寸图标；提供明暗背景和单色版本。
- 浅色：暖白画布、白色内容面、墨色文字、适量青绿重点操作；用字号、分组、间距建立层级。
- 深色：石墨灰画布与三级表面，柔和浅色文字；青绿仅用于动作与选中反馈，状态色单独定义。
- 页面：固定节奏的页头与操作区，有内容时优先展示下一步，空白时提供开始路径；减少无意义大块空白和重复卡片边框。
- 状态：加载、空、错误、成功、选中、禁用、执行中、未保存均能区分；保留原有草稿保护、焦点恢复、键盘与手机体验。

## 验证要求

逐页检查桌面与手机、浅色与深色，并覆盖有数据/空数据、加载/失败、交互焦点和主要操作。模型分类只使用已知模型标识与现有配置能力，不编造模型质量或性能。官方标识须记录来源；未知品牌使用明确中性标识。

完成后执行相关单元、浏览器回归、类型检查、构建与 GitHub CI，并按既有授权部署腾讯云，核对 GitHub/服务器/线上 revision、公开 readiness 与真实页面冒烟。真实收费与供应商生成的验收边界保持单独记录。
