# 漫角功能入口与组件按钮自检

基线：`4a109c0`。延续用户“排查功能上和组件按钮上的缺以及优化”的要求，直接修复本地可复现问题。前台沿用暖白与青绿，后台保持现有 sub2API 布局体系。

## 本轮修复

| 范围 | 原问题 | 修复后的操作 |
| --- | --- | --- |
| 制作台任务弹窗 | 未传入重试、取消处理器，操作入口不出现 | 接入真实任务 API；按任务状态及服务端能力展示操作，成功、失败均有反馈 |
| 制作台与生成队列 | 操作已受理但刷新失败后，仍可再次重试原任务 | 区分请求拒绝和状态刷新失败；后者锁定该任务操作，提供只刷新恢复，关闭弹窗再打开仍保留锁定 |
| 生成队列 | 已退款任务只能混在全部记录里查找 | 增加“已退款”筛选，保留状态说明及重试能力限制 |
| 我的作品 | 故事手稿缺少删除入口，漫剧删除说明与保留历史的服务端行为不一致 | 两类作品都有确认、处理中、失败重试和成功提示；明确已交接漫剧、任务及积分历史的保留范围 |
| 内容工作区 | 删除期间可再次点击；删除成功后的列表读取失败被显示为删除失败；删除当前 URL 指向的项目后会错误进入“找不到项目”页 | 删除互斥；确认成功后立即更新本地作品与父级列表，清理缓存与编辑器，选择剩余作品或进入新建；刷新失败保持删除成功提示 |
| 资产生成与参考图 | 生成时仍可更改参考图，读取上传文件时没有锁定，生成参数仍可修改 | 生成、参考图保存及上传互斥；处理期间锁定对象切换及模型、尺寸、质量；上传显示进度并校验格式及 8 MB 上限 |
| 模型控件 | 历史数据缺少模型字段时对空值调用 trim，整个页面报错 | 模型名称处理接受 null/undefined，控件显示选择提示；不自动更换模型 |
| 后台价格 | 新增时空值被转换为免费价格，编辑时允许小数积分 | 新增和编辑共用校验：积分为非负安全整数，配置成本为非负有限数，明确输入 0 才表示零价格；关联渠道时模型类型由渠道确定 |
| 后台内容进度 | running、succeeded、confirmed、stale 等真实状态显示英文原值 | 补齐生成中、已生成、已确认和内容待更新等中文标签 |
| 评测弹窗 | 刷新可重复点击，失败被父页面吞掉，弹窗中没有反馈 | 弹窗内显示加载、成功和错误，刷新期间禁用操作，保留刷新重试入口 |

实际生产工作区使用 `ContentStage`、`AssetStage`、`ShotStage`、`DeliveryStage`；未将注释掉的旧工作区按钮算作当前缺失功能。

全站浏览器回归覆盖 110 项。按每个用例的最新结果汇总，108 项通过，2 项需要真实认证项目 URL 的检查跳过。首轮为 105 通过、3 失败、2 跳过：两项失败来自审核分页接口夹具错误返回数组，一项来自旧主题测试在初始化完成前改写偏好。修正夹具并补强主题断言后，复核受影响的 28 项；其中新增按钮场景 20 项全部通过，主题与首页文件最后复核为 6 通过、2 跳过。减少动效检查显式启用浏览器媒体设置并断言页面动效变量为 `0ms`。所有运行都关闭自动重试；该汇总为分组复核结果，不是一轮 108 项全部通过的运行。

完整验收记录与机器可读结果见 `outputs/button-function-review-20261026/验收记录.md` 和 `verification.json`，原始检查日志保存在同目录的 `logs`。
