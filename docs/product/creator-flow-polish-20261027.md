# 创作续接与问题反馈迭代

本轮围绕工作台、我的作品、生成队列和帮助中心，补齐创作者从“继续创作”到“排查问题”的入口与反馈。前台沿用暖白与青绿，后台沿用现有管理台布局。

## 交付范围

| 页面 | 行为与视觉变化 |
| --- | --- |
| 工作台 | 最近故事独立展示；比较最近故事和漫剧的更新时间，优先续接最近创作；提供阶段提示与下一步操作。读取故事失败时显示重试入口，不把未读到的数据当作空白账户。 |
| 待办卡片 | 正在生成、失败待处理跳到对应筛选；最近任务直接定位详情；待确认数量存在而抽样项目为空时仍可进入全部作品。 |
| 我的作品 | 支持按最近更新、名称排序；故事与漫剧分别每页 12 项；搜索、筛选、排序重置分页；删除末页最后一项后回到有效页。卡片标明下一步操作，统一悬停与焦点反馈。 |
| 生成队列 | 支持 `#/tasks?status=failed` 与 `#/tasks?task=<平台任务编号>`；链接可刷新和切换，定位跨页任务；手机端选中任务后聚焦详情，并提供返回列表入口。 |
| 帮助中心 | 任务详情带入诊断草稿，用户检查后提交；保留已有未提交内容，由用户选择是否追加任务信息；重复内容不追加，超过 5000 字时保留原稿并提示。 |
| 工单界面 | 新建表单使用独立宽度；列表可滚动；移动端表单和按钮布局更清晰；状态与帮助页切换标签适配深色主题。用户与后台共用的工单样式保持一致。 |

## 行为约束

- 跳到帮助中心不会自动创建工单；点击提交才发出请求。
- 草稿按账户和角色隔离。诊断摘要使用平台任务编号，不带供应商内部任务编号。
- 路由切换重新建立任务页状态；后台刷新不会把用户拉回原直达任务。
- 分页、排序不修改作品本身，也不改变服务端任务状态。

## 验证方法与边界

- 模型单元检查覆盖路由参数、稳定排序、下一步文案、诊断草稿、已有内容合并与长度限制。
- 桌面和移动浏览器覆盖故事续接、读取失败恢复、独立分页、末页删除、搜索、任务跨页定位、同页链接切换、刷新、工单草稿与明确提交。
- 全量回归继续检查原有管理台、内容创作、剪辑、计费展示和工单流程；生产发布后另查公开页面与运行版本。
- UI 回归使用隔离接口夹具。数据库集成检查由 CI 的独立 PostgreSQL/Redis 执行。两类证据均不替代真实供应商生成质量、真实现金支付与新售价验收。

本轮没有服务端或数据库结构变更。具体测试结果和生产发布证据保存在本机 `outputs/creator-flow-polish-20261027/验收记录.md`。
