01 · 售价如何换算

业务假设：利润百分之40 = 40% 毛利率。
毛利率 =（收入 − 官方 API 成本）÷ 收入。基础售价 = 官方成本 ÷ 0.6。若你指的是成本加价40%，对应售价是成本 × 1.4，毛利仅约28.57%；后台可调整目标比例。
100基础名义兑换：1 元 = 100 积分
1.6667×40% 毛利的成本售价倍数
1 次每次任务用量汇总后向上取整

成本内部按整数微元计算，钱包保持整数积分。文本输入、输出和缓存分别计价；每个请求单独选择长上下文档位，再合计费用。图片按成功交付张数，视频按供应商实际采用的时长和规格，配音按 Unicode 字符总数；不对每个字符先取整。

定价政策包括目标毛利、每积分人民币价值、美元结算汇率、运营费用比例和促销保护。美元成本未配置汇率时禁止应用。政策生效后只影响新任务，已冻结任务沿用快照。运维、支付手续费、税费等只有明确录入后才纳入公式，40% 不代表企业净利润。

03 · 创作者的积分使用流程

选择模型、规格与内容→ 确认报价上限→ 冻结应付积分→ 生成与计量→ 实扣 + 释放余款

FR-02 · 钱包与明细

钱包、侧栏和资料页统一展示可用积分，并在明细列出总余额和冻结。可用 = 总余额 − 冻结；冻结不会减少总余额，也不计入消费。明细支持服务端分页、类型筛选、说明或任务搜索、本地日期完整起止日筛选及导出当前筛选页。CSV沿用当前页码与每页数量。账户读取失败显示重试状态，不能把流水局部合计冒充累计充值或消费。

FR-03 · 报价与消费

确认前显示所选渠道、模型、单位、预估用量和积分上限。任务保存政策、成本规则、原价、实际减免与应付快照。只冻结应付额度。文本具备供应商 usage 时按 Token 结算；没有 usage 的历史或手工模式按已确认固定额度处理并标注成本未核验。超出确认上限由平台承担差额，记录对账异常，不静默追扣。

图片批次部分成功只收成功图片费用，剩余冻结释放。取消和失败只释放该任务余款。配音缓存复用不重复收费；已付费文件丢失需恢复存储，不要求用户再付款。结果已成功但页面刷新失败时先查询已有任务，不能自动再次提交。

FR-04 · 充值、兑换与人工调整

支付回调核验金额、商户和交易号后，订单与流水、钱包、资金批次在同一事务内入账；重复回调不二次赠送积分。兑换码校验有效期、次数、批次启用和本人重复兑换。手工调整必须填写原因并生成流水；负向调整不能动用冻结积分，且不再计入生成消费。

现有微信付款保持关闭。本轮通过隔离测试验证代码原子性，不能代替真实收款验收。卡密的实收来源未核验时保留未知，避免编造销售收入。

04 · 后台积分中心

FR-05 · 账户与流水

商业化导航新增“积分中心”，沿用后台表格、筛选栏与青绿语义样式。账户页展示用户、可用、冻结、总余额、累计充值和生成消费；选择用户查看流水与资金批次。跨用户查询需要积分管理权限，前台始终只能读取本人账务。积分调整继续使用现有专门权限和幂等请求标识。

FR-06 · 定价政策与成本规则

管理员编辑毛利、基础积分价值、美元汇率、运营费用和保护开关。保存前展示公式及有效积分价值，保存时校验版本。已被其他管理员更新时要求刷新，不覆盖。官方目录匹配当前模型后，先预览旧价、新价和成本依据，再逐条应用；未知模型不会自动绑定相似名称。

FR-07 · 任务对账与成本核验

按用户、任务、模型和状态查询预估、实扣、释放、用量、资金分摊和成本证据。区分未核验、按usage推导、按交付数量推导及真实账单核验。显示超上限、路线不匹配和账务差异。任务结束后可录入真实账单金额与凭据，保留核验时间和操作审计；操作不会改写用户已结算积分。

后台所有写操作沿用操作审计。账单核验和价格应用必须校验版本。读取失败显示错误，空查询显示无记录；跨用户记录导出仅向有权限管理员开放，CSV处理公式注入和引号转义。

05 · 充值赠送、现金收入与利润

100元买10,000积分再赠送2,000积分，实际每积分价值约0.008333元。仍按0.01元定价并给予10%会员减免，会进一步压低毛利。因此保护模式取启用的付费套餐、订阅方案与仍有余额的历史核验付费批次中最低积分价值重新换算售价，后台显示实际采用的价值；停售或套餐调价不移除已有低价余额，批次耗尽才退出保护。手工价格必须由运营评估成本底价。

资金批次在账户锁内维护，以递增入账序号按 FIFO 分摊，确保同一事务时间戳下顺序稳定、批次余额合计与总余额一致。冻结以任务流水作为所有权凭据，不能从别的任务扣除。历史批次首次参与新结算或入账时按原余额补齐为“未知来源”；历史账务与人工扣减差异进入对账，需按凭据修复。

供应商可能在内容解析失败、文件保存失败、取消或退款前已经产生费用。保留已取得的usage与对应成本，平台承担未交付部分。重试绑定执行轮次，前次未能保存的响应不算作本次交付；迟到成本保留且不覆盖已核验账单。没有usage或账单时显示未知成本；现金毛利仅在实收来源及真实账单均核验后显示。赠送、未知来源、失败费用及封顶补贴不保证40%现金毛利，真正的月度利润仍须核对供应商账单、支付账单、卡密销售和运营费用。
