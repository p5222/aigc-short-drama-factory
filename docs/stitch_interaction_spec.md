# AI 漫剧创作云交互与 UI 设计说明

这份文档用于给 Stitch 生成前台 UI 图和后台管理系统交互页面。当前产品是一个 AI 漫剧/短剧生产 SaaS，核心路径是：登录 -> 工作台 -> 新建漫剧 -> 生成剧本 -> 进入项目生产台 -> 生成分镜 -> 生成角色图/分镜图/视频草稿 -> 积分与任务管理。

## 1. 前台登录首页

### 页面目标

- 展示 AI 漫剧创作云的品牌感、模型能力和“从故事到视频”的产品定位。
- 让用户完成登录或免费注册。
- 支持调节首页视觉位置：访问 `/?layout=1` 后出现像素调节面板。

### UI 结构

- 全屏动态视频背景，叠加柔和暗色遮罩，突出前景内容。
- 左侧为悬浮毛玻璃品牌面板：
  - NEW 标签。
  - 主标题：AI 漫剧创作云。
  - 能力标签：小说改编、分镜生成、成片合成。
  - 描述文案：从故事到漫画视频，一站完成创意落地。
  - 模型能力区：OpenAI、Claude、Gemini、DeepSeek、通义千问、豆包，图标放在圆形玻璃底托中。
- 右侧为毛玻璃登录控制面板：
  - 标题：登录创作平台 / 注册创作账号。
  - 登录/免费注册切换。
  - 手机号/邮箱输入框，左侧线性用户图标。
  - 密码输入框，左侧锁图标。
  - 图形验证码输入框 + 验证码刷新按钮。
  - 主按钮：立即登录 / 免费注册。
  - 错误提示显示在按钮下方。

### 交互逻辑

- 登录 tab：
  - 输入手机号或邮箱、密码、验证码。
  - 点击“立即登录”。
  - 前端校验验证码和密码长度。
  - 请求 `/api/auth/login`。
  - 成功后保存 token 到 `localStorage`，进入工作台。
  - 失败后刷新验证码并展示错误。
- 注册 tab：
  - 输入手机号、邮箱、验证码、密码、确认密码。
  - 勾选协议。
  - 点击“免费注册”。
  - 请求 `/api/auth/register`。
  - 成功后直接进入工作台。
- 验证码：
  - 点击验证码块刷新。
  - 不区分大小写。
- 布局调节：
  - `/?layout=1` 显示右下角像素调节面板。
  - 可调左侧 X/Y、标题字号、整体缩放、模型间距、登录框 X/Y/宽度。
  - 数值保存在浏览器 localStorage。

### 可优化点

- 增加短信验证码登录。
- 增加第三方登录。
- 登录成功后根据用户是否有未完成项目，跳转到最近项目或工作台。

## 2. 后台登录页

### 页面目标

- 让管理员、运营、财务、客服等后台角色登录。
- 风格必须轻量、专业、浅蓝、极简，不使用黑色输入块。

### UI 结构

- 全屏浅蓝背景 `#F0F8FF`。
- 居中白色登录卡片：
  - 标题：后台管理系统。
  - 副标题：登录后管理用户、积分、兑换码、模型渠道和计费策略。
  - 管理员邮箱输入框，左侧用户图标，focus 蓝色描边。
  - 密码输入框，左侧锁图标。
  - 验证码输入框 + 浅灰验证码盒。
  - 提示：点击验证码可刷新，不区分大小写。
  - 主按钮：进入后台。
  - 底部默认账号：admin@aifilm.local / admin123456。

### 交互逻辑

- 访问 `/admin`。
- 未登录时显示后台登录页。
- 登录成功后检查角色：
  - `admin/operator/finance/support` 可进入后台。
  - `creator` 拒绝进入后台。
- 登录后进入后台管理系统，默认模块为“运营总览”。

### 可优化点

- 增加后台登录日志。
- 增加二次验证。
- 增加不同角色登录后的默认模块跳转。

## 3. 前台主工作台

### 页面目标

- 给创作者提供项目总览和快速入口。

### UI 结构

- 左侧固定导航：
  - 工作台。
  - 新建漫剧。
  - 我的作品。
  - 剪辑中心。
  - 任务中心。
  - 我的、积分充值、积分明细、设置、帮助中心。
- 顶部栏：
  - 面包屑。
  - 搜索框。
  - 新手引导。
  - 主题切换。
  - 通知。
  - 用户名和退出。
- 主内容：
  - 项目数量、任务、积分等指标卡。
  - 最近作品。
  - 快速创建入口。

### 交互逻辑

- 点击“新建漫剧”进入创作向导。
- 点击作品卡进入项目生产台。
- 点击积分充值进入充值页。
- 点击任务中心查看任务状态并重试/取消。
- 退出登录会调用 `/api/auth/logout` 并清空本地 token。

## 4. 新建漫剧创作向导

### 页面目标

- 复刻 U 漫式流程，把用户从故事输入引导到全局设定、剧本生成、资产生成。

### 步骤结构

1. 故事输入
   - 粘贴小说/故事/剧本。
   - 支持导入 `.txt`。
   - 显示字数和建议集数。
   - 可保存草稿。
2. 全局设定
   - 视频发布平台/画幅：竖屏 9:16、横屏 16:9。
   - 画面风格：真实漫画、真人电影感、真人古装、真人复古港片等。
   - 生成模式：9 宫格、25 宫格。
3. 核心剧情与剧本
   - 选择文本模型，默认 DeepSeek。
   - 测试文本模型连接。
   - 估算积分。
   - 生成全局设定、剧情、剧本。
4. 分镜/资产生成
   - 选择生图模型，默认通义千问/Qwen Image。
   - 测试生图模型。
   - 进入项目工作台继续生成分镜图和视频资产。

### 交互逻辑

- 没有故事正文时不允许进入后续步骤。
- 自动保存草稿到 localStorage。
- 点击“生成”后请求 `/api/creation/start`。
- 成功后进入项目生产台。
- 模型测试失败时提示具体原因，不影响保存草稿。

### 可优化点

- 在第 2 步增加角色数量、目标时长、叙事节奏。
- 在第 3 步增加剧本预览与可编辑确认页，再进入资产生成。

## 5. 项目生产台

### 页面目标

- 承接创作向导生成的项目，完成分镜、角色参考图、分镜图、视频草稿和导出。

### UI 结构

- 顶部项目标题、简介、返回、刷新、导出分镜。
- 流程进度条：策划、剧本、角色、分镜、分镜图、图生视频、配音字幕、合成导出。
- 指标卡：剧集、角色、镜头、已用积分。
- 生成控制台：
  - 下一步主按钮。
  - 分镜表/角色参考图/分镜图/视频草稿完成度。
  - 最近任务进度。
- Tab：
  - 镜头导演台。
  - 分镜图画廊。
  - 视频时间线。
  - 分镜表。
- 下方：
  - AI 剧本。
  - 角色一致性资产。
  - 基础素材库。

### 交互逻辑

- 没有分镜时，主按钮为“生成分镜表”。
- 有分镜但无角色参考图时，主按钮为“生成角色参考图”。
- 有角色参考图但无分镜图时，主按钮为“生成分镜图”。
- 有分镜图但无视频草稿时，主按钮为“生成视频草稿”。
- 全部完成后主按钮变为完成状态。
- 分镜图生成会消耗积分并写入资产。
- 视频草稿当前为可替换的占位流程，后续接真实图生视频。
- 导出分镜会下载 JSON 文件。

### 可优化点

- 分镜表行内编辑。
- 单镜头重绘按钮。
- 视频提示词编辑。
- 多版本资产对比。

## 6. 任务中心

### 页面目标

- 查看生成任务状态，处理失败任务。

### UI 内容

- 任务列表：
  - 项目名。
  - 任务类型：文本、分镜、图片、视频等。
  - 模型供应商和模型名。
  - 状态：pending/running/succeeded/failed/canceled/refunded。
  - 进度。
  - 预估积分和实际积分。

### 交互逻辑

- running/pending 任务前台轮询刷新。
- failed 任务可重试。
- pending/running 任务可取消。
- 失败原因显示在任务行中。

## 7. 积分充值与积分明细

### 页面目标

- 让用户充值积分、查看积分流水、兑换体验码。

### UI 内容

- 充值包卡片：
  - 套餐名。
  - 价格。
  - 到账积分。
  - 赠送积分。
  - 是否启用由后台控制。
- 会员方案：
  - 月费。
  - 每月积分。
  - 折扣。
  - 优先级。
- 兑换码输入。
- 积分明细表：
  - 类型：recharge/consume/refund/freeze/redeem/adjust。
  - 金额。
  - 余额。
  - 任务/项目关联。
  - 时间。

### 交互逻辑

- 前台只展示后台启用的套餐和会员。
- 兑换码每个 code 有最大次数，批量生成时每份 code 唯一。
- 消费时先判断余额和冻结余额。

## 8. 后台管理系统

### 后台整体结构

- 访问 `/admin`。
- 登录后进入独立后台布局。
- 左侧为模块导航。
- 每个模块是一个页面/页签，不是长瀑布。
- 顶部显示后台名称、当前账号、退出。
- 后台接口有角色权限控制。

### 角色权限

- `admin`：全部权限。
- `operator`：运营总览、模型路由、兑换码、模板查看。
- `finance`：运营总览、套餐会员、价格策略、用户查看、积分调整。
- `support`：运营总览、用户查看、积分调整。
- `creator`：不能进入后台。

### 模块 1：运营总览

- 展示注册用户、项目数量、任务成功率、已消耗积分。
- 展示计费策略说明：
  - 低成本闭环。
  - 专业模式。
  - 后台可控。
- 交互：
  - 点击刷新配置重新拉取后台数据。

### 模块 2：用户积分

- 表格字段：
  - 用户名/邮箱。
  - 角色。
  - 余额。
  - 冻结积分。
  - 累计充值。
  - 项目数。
  - 状态。
  - 手动调整。
- 交互：
  - 修改用户名称、角色、状态。
  - 输入积分变动数值和说明。
  - 点击“账号”保存用户资料。
  - 点击“入账”写入积分流水。

### 模块 3：兑换码

- 批量生成唯一兑换码：
  - 活动名。
  - 前缀。
  - 到账积分。
  - 生成份数。
  - 启用状态。
- 兑换码列表：
  - code。
  - 活动名。
  - 到账积分。
  - 最大兑换次数。
  - 已使用次数。
  - 批次 ID。
  - 启停。
- 交互：
  - 生成 N 份不同 code。
  - 每个 code 默认只可用 1 次。
  - 保存单个兑换码配置。

### 模块 4：套餐会员

- 管理一次性充值包。
- 字段：
  - 套餐名。
  - 售价。
  - 到账积分。
  - 赠送积分。
  - 标签。
  - 卖点。
  - 启用状态。
- 交互：
  - 编辑后保存。
  - 关闭后前台充值页自动隐藏。

### 模块 5：订阅会员

- 管理月度会员。
- 字段：
  - 会员名。
  - 月费。
  - 每月积分。
  - 折扣百分比。
  - 队列等级。
  - 权益说明。
  - 启用状态。
- 交互：
  - 编辑后保存。
  - 关闭后前台自动隐藏。

### 模块 6：模型路由

- 管理模型供应商。
- 字段：
  - 启用状态。
  - Base URL。
  - 模型列表。
  - 成本说明。
- 交互：
  - 保存供应商配置。
  - 文本模型测试连接。
  - 生图模型测试连接并预览返回图片。
  - 视频模型测试连接。
- 注意：
  - API Key 不在前端编辑，仍从服务器 `.env` 读取。

### 模块 7：价格策略

- 管理模型计费表。
- 字段：
  - 供应商。
  - 模型。
  - 类型：text/image/video/tts/embedding。
  - 单位。
  - 积分单价。
  - 成本人民币。
  - 启用状态。
- 交互：
  - 修改积分单价。
  - 修改成本记录。
  - 启停模型价格。
  - 生成任务优先读取启用价格。

### 模块 8：提示词模板

- 展示提示词模板版本和摘要。
- 字段：
  - 模板名。
  - 类型。
  - 版本。
  - 摘要。
  - 启用状态。
- 交互：
  - 当前主要是展示，后续可扩展编辑、灰度、版本回滚。

## 9. 系统基础能力

### 登录系统

- 使用数据库会话 `AuthSession`。
- token 存在前端 localStorage。
- 后端校验 token hash、过期时间、用户状态。
- logout 会吊销 session。

### 队列

- 使用 BullMQ。
- 生成任务支持重试。
- 环境变量：
  - `GENERATION_JOB_ATTEMPTS`
  - `GENERATION_JOB_BACKOFF_MS`

### 对象存储

- 本地使用 `storage/`。
- 图片生成结果会归档为 `/storage/images/...`。
- 生产可替换为 OSS/S3/COS。

### 日志与健康检查

- `/health`：API 基础健康。
- `/api/system/health/dependencies`：数据库和 Redis 健康。
- `API_ACCESS_LOG=true` 可打印全部请求。

### 限流

- 登录接口默认 60 秒 30 次。
- 普通接口默认 60 秒 180 次。

## 10. Stitch 生成建议

### 前台 UI 图应生成这些画面

1. 登录首页：视频背景、左侧毛玻璃品牌面板、右侧毛玻璃登录面板。
2. 工作台：侧边栏、顶部栏、数据卡片、最近项目。
3. 新建漫剧：四步向导。
4. 项目生产台：生成控制台 + 镜头导演台。
5. 分镜图画廊。
6. 任务中心。
7. 积分充值与流水。

### 后台交互页面应生成这些画面

1. 后台登录页：浅蓝背景白卡。
2. 运营总览。
3. 用户积分管理。
4. 批量兑换码生成与兑换码列表。
5. 套餐会员管理。
6. 订阅会员管理。
7. 模型路由与测试连接。
8. 价格策略表。
9. 提示词模板管理。

### 设计风格建议

- 前台：深色电影感、毛玻璃、沉浸式、适合创作者。
- 后台：浅色、低噪音、高密度、表格清晰、操作按钮明确。
- 表单：所有输入框都有图标、focus 状态、错误提示。
- 管理页：每个模块独立页面，避免长滚动。
