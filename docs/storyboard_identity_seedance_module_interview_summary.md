# 角色身份板、故事板首帧与 Seedance 视频模块总结

更新时间：2026-07-04

## 模块意义

这个模块解决的是 AI 漫剧生产里最核心的稳定性问题：角色会漂、故事板太密、视频片段不连贯。

传统做法是把剧本直接丢给图片或视频模型，结果每个镜头都可能重新发明角色外貌、服装和场景。现在的方案把生产拆成：

1. 角色身份板。
2. 场景卡。
3. 故事板首帧。
4. Seedance 图生视频。
5. 质量评测和重生。

它的价值是把不可控的一次性生成，变成可检查、可重试、可评测、可版本迭代的生产流水线。

## 目标

- 先锁定角色一致性，降低换脸、换发型、换服装主色。
- 让故事板只负责构图、站位、动作起点和首帧锚定，不让它承载过多噪点。
- 让 Seedance 视频生成拿到首帧、主动作、尾帧和连续性交接，提高短片段可剪辑性。
- 让中长剧走角色卡和场景卡路线，而不是依赖一张密集故事板。
- 把失败原因、用户反馈、质量评测沉淀为后续提示词优化数据。

## V1 已落地

- 新增后端生产提示词模块：`apps/api/src/agents/storyboardProduction.ts`
- 角色参考图升级为角色身份板：
  - 正面全身。
  - 3/4 侧面全身。
  - 背面全身。
  - 半身大头照。
- 上传角色图时，提示词要求先抽取视觉签名，再生成身份板。
- 分镜图生成改为“故事板首帧提示词”，带入角色参考、场景参考、镜头语言、站位和避免项。
- 视频生成改为“Seedance 视频段提示词”，带入首帧锚点、尾帧锚点和连续性交接。
- 单镜头重生也接入同一套首帧提示词，避免批量生成和单镜头重生规则不一致。

## V2 已落地

- 新增故事板生产方案接口：
  - `GET /api/projects/:id/storyboard-production-package`
- 前端生产台新增“故事板生产方案”面板：
  - V1 基础闭环自检。
  - V2 中长剧稳定性自检。
  - V3 成熟迭代自检。
  - 场景卡候选。
  - 质量门槛。
  - 自动修复规则。
- 生产包会根据当前项目资产统计：
  - 角色数。
  - 角色身份板数。
  - 场景卡数。
  - 镜头数。
  - 首帧数。
  - 视频片段数。

## V3 已落地

- 后台提示词模板种子新增：
  - `tpl_character_identity_board_v1`
  - `tpl_storyboard_first_frame_v1`
  - `tpl_seedance_segment_v1`
  - `tpl_storyboard_auto_repair_v1`
- 这些模板让后续提示词可以从后台迭代，不必每次改代码。
- 生产包中明确了自动修复策略：
  - 角色漂移：重生身份板或要求上传更清晰参考图。
  - 首帧有字幕/水印/构图不可用：强化避免项并重生本镜头。
  - 视频不可剪辑：缩短时长，强化首尾帧锚点，必要时重生首帧或换视频模型。
- 生产包中明确了数据闭环：
  - 用户选中/废弃/重生原因进入反馈。
  - 质量评测进入后台看板。
  - 高分镜头做正例，低分镜头做负例，继续优化提示词。

## 面试回答版

我在项目里负责过一个 AI 漫剧生产稳定性模块，重点解决角色一致性和图生视频连续性。

最初如果直接用文本生成分镜图和视频，角色很容易在不同镜头里换脸、换发型、换衣服，视频模型也经常因为提示词太密而生成不可剪辑的片段。我把流程拆成了“角色身份板 -> 场景卡 -> 故事板首帧 -> Seedance 图生视频 -> 质量评测”的流水线。

角色阶段不再只生成普通头像，而是生成一张角色身份板，包含正面全身、3/4 侧面、背面和大头照。如果用户上传角色图，会先把上传图作为身份源，提示词要求模型抽取脸型、发型、服装主色、体态等视觉签名，再延展成身份板。这样后续分镜图只引用角色资产，不再重新发明外貌。

分镜图阶段，我把普通图片提示词升级成“故事板首帧提示词”，它会带入角色参考、场景参考、景别、机位、站位、主动作和避免项。这个首帧不是为了做漂亮插画，而是为了让视频模型拿到稳定的开场画面。

视频阶段，我为 Seedance 生成结构化提示词，包含首帧锚点、尾帧锚点、连续性交接、声音和避免项。每段优先控制在 6 到 12 秒，最多 15 秒，只承载一个连续微节拍，这样更适合后期剪辑。

为了让它可运营，我还做了生产方案面板和后台提示词模板。前台可以看到角色身份板、场景卡、首帧、视频片段的完成度；后台可以版本化管理角色身份板、故事板首帧、Seedance 视频段和自动修复模板。后续用户的重生原因、质量评分和模型失败信息都能沉淀为数据，用来优化提示词和模型路由。

这个模块的结果是把不可控的一次性生成，变成了可检查、可重试、可评测、可迭代的 AIGC 视频生产链路。
