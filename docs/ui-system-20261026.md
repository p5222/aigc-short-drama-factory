# 漫角 UI 与图标迭代

## 前台：创作手帐

延续暖白和青绿，将创作空间整理为“故事、制作、交付”三个清楚的视觉层级。背景使用暖纸白 `#F7F8F6`，内容面板为白色，正文松墨色 `#24312D`，主要操作松绿 `#0B7768`。深色主题采用深松绿画布和浅青绿操作色。

- 字号：页面标题 28–32px，区块标题 16–18px，正文 14px，辅助内容 12px；数字使用等宽数字。
- 图标：Lucide 圆端细线，24 单位网格，常规 18px、导航 20px、功能入口 24px，线宽 1.75。功能图标不使用彩色 emoji；纯图标按钮有中文名称和悬停提示。
- 创作阶段：故事用 BookOpenText，角色资产用 ScanFace，分镜用 Clapperboard，交付用 Film；在工作台、创作入口和生产台保持对应关系。
- 布局：左栏放创作导航，顶部放搜索、主题和账户，页面首屏展示继续创作、待办、最近作品。通过章节序号、细分隔线和阶段图标建立作品感。
- 状态：成功、警告、失败同时包含文字和图标；空态给出下一步，加载与读取失败分别处理。
- 操作：悬停和焦点使用细边框/浅底，过渡 160ms；减少动态效果设置下关闭装饰动效。手机保留完整导航及主要操作。

## 后台：Sub2API 组件还原

参考 2026-10-26 读取的官方源文件：

- [主题配置](https://github.com/Wei-Shaw/sub2api/blob/main/frontend/tailwind.config.js)
- [基础样式](https://github.com/Wei-Shaw/sub2api/blob/main/frontend/src/style.css)
- [弹窗组件](https://github.com/Wei-Shaw/sub2api/blob/main/frontend/src/components/common/BaseDialog.vue)
- [用户管理](https://github.com/Wei-Shaw/sub2api/blob/main/frontend/src/views/admin/UsersView.vue)

尺寸和结构按官方组件对照；保留漫角品牌、真实业务字段及权限约束。主要按钮使用更深的 teal-700 以提高白字对比度，这一颜色取舍与官方默认渐变有差别。

|组件|实现标准|
|---|---|
|侧栏/顶栏|256px 侧栏、64px 品牌栏与顶栏；12px 选中项圆角|
|画布|gray-50、白色表面；深色 slate-950/800/900|
|控件|12px 圆角、42px 高、14px 字号|
|表格|浅灰表头、细分隔线、右侧固定行操作、区域横向滚动|
|新增/编辑|512/576/768/896px 分档居中弹窗、16px 圆角|
|滚动|最大 90dvh；手机 95dvh；标题、取消和提交固定，正文独立滚动|
|确认|448px 站内确认框；危险图标、影响说明、取消与明确的确认动作|
|用户操作|资料与权限、积分调整、账号安全三个入口；草稿切换保留|
|键盘|焦点限制、背景 inert、Escape 关闭顶层、关闭后回到触发按钮|
|保存|提交时禁止重复操作；失败保留输入并在当前弹窗显示结果|

## 实施与验收范围

本轮覆盖前台工作台、作品库、创作入口、生产阶段、队列、账户、计费、帮助及公开入口；后台覆盖 13 个主模块和新增、编辑、详情、删除/停用确认。样式规范、业务回归与生产发布分别留证。

本地浏览器使用隔离测试数据，不写入生产。真实支付和付费模型生成不属于本轮 UI 验证的证据范围。

## 已落地的组件

- `design-system/StudioIcon.tsx` 定义四个阶段图标、中文阶段名称与折页对话品牌标记；工作台、创作入口、作品库和生产台共用。
- `design-system/studio-notebook.css` 实现作品左侧书脊线、章节编号、当前阶段标识、双主题及手机排版；不改变首页透明导航与视频原色。
- `admin/AdminDialog.tsx`、`AdminMasterDetail.tsx`、`AdminConfirm.tsx` 统一新增、编辑、详情与二次确认。用户资料、积分及密码操作的提交按钮固定在底部，保留原生表单校验。
- 编辑公告、帮助、兑换码、充值套餐、订阅方案、模型渠道、价格策略均在弹窗内完成；保存失败保留草稿并可再次提交。
