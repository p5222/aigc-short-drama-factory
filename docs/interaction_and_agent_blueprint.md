# 漫角项目交互与智能体蓝图

更新时间：2026-06-30

## 一、前台首页与登录

### 首页首屏
- 品牌：漫角 / AI 漫剧生产台。
- 背景：保留本地循环视频 `cinematic-login-bg.mp4`，覆盖暗色渐变，确保文字可读。
- 左侧内容：占首屏左侧约 45%，大标题、三段能力标签、两段说明、模型图标圆底托。
- 模型图标：当前展示 OpenAI、Claude、Gemini、DeepSeek；通义千问、豆包只保留后台模型能力，不在首页占位展示。
- 可调试入口：访问 `/?layout=1` 可以调整文案 X/Y、标题字号、整体缩放、模型间距、登录框 X/Y/宽度。

### 登录注册模块
- 结构：标题、登录/注册 tab、账号输入、密码输入、图形验证码、协议确认、红色主按钮。
- 登录：手机号或邮箱 + 密码 + 验证码。
- 注册：手机号 + 邮箱 + 验证码 + 密码 + 确认密码 + 协议。
- 成功后：写入 `aifilm_auth_token`，前端调用 `/api/auth/me` 保持登录态。
- 退出登录：调用 `/api/auth/logout` 后清理本地状态。

## 二、前台创作工作流

### 工作台
- 显示用户项目数量、分镜数、任务数、积分。
- 展示最近项目与最近任务。
- 入口：新建漫剧、打开项目、进入任务中心。

### 创作向导
- 流程参考 U 漫：故事输入 -> 全局设定 -> 核心剧情/剧本 -> 分镜/资产生成。
- 第一步输入故事/小说/剧本/脑洞，选择 9 宫格、25 宫格或导演模式。
- 第二步确定平台比例、画风、题材等全局设定。
- 第三步生成剧情梗概、剧本、角色卡。
- 第四步生成分镜表、角色参考图、分镜图、视频草稿。

### 项目生产台
- 顶部：项目标题、阶段进度、导出分镜、刷新。
- 生产控制台：下一步按钮自动判断应生成分镜、角色参考图、分镜图或视频草稿。
- 镜头导演台：左侧镜头列表，中间画面预览，右侧镜头属性、台词、提示词、资产状态。
- 分镜图画廊：按镜头顺序展示图片资产。
- 视频时间线：按分镜图生成视频草稿任务。
- 分镜表：用于核对台词、旁白、音效、图片提示词、视频提示词和资产 ID。

### 任务中心
- 任务类型：文本、分镜图、视频、TTS、导出。
- 状态：pending、running、succeeded、failed、canceled、refunded。
- 操作：失败/未完成任务可以重试或取消。
- 目标 UI：深色生产台表格，清晰显示项目名、步骤、状态、进度、错误原因。

## 三、后台管理系统

### 后台登录页
- 风格：浅蓝全屏背景 + 白色卡片。
- 输入：管理员邮箱、密码、图形验证码。
- 默认账号：`admin@aifilm.local / admin123456`。

### 后台模块
- 运营总览：用户数、项目数、任务成功率、积分消耗、策略说明。
- 用户积分：用户角色、状态、余额、冻结积分、累计充值、手动入账。
- 兑换码：批量生成唯一兑换码，每个 code 默认只可兑换 1 次，后台保留批次和使用记录。
- 套餐会员：充值包上下架、价格、到账积分、赠送积分、卖点。
- 订阅会员：月费、月度积分、折扣、队列等级、权益。
- 模型路由：供应商启停、Base URL、模型列表、测试连接、网关策略预览。
- 智能体工厂：长篇写作 Agent 和角色一致性 Agent 的预览测试。
- 价格策略：模型单价、供应商成本、启停状态。
- 提示词模板：规划、剧本、分镜、角色、图片、视频、审核模板版本。

## 四、开源项目嵌入策略

### webnovel-writer
- 参考点：长篇网文的世界观、章节大纲、记忆卡、连续性检查。
- 落地方式：已新增自有实现 `createWebNovelWritingPlan`。
- 当前输出：logline、世界规则、角色弧线、卷纲、章节目标/冲突/钩子、记忆卡、审查清单。
- 后续接入：创作向导故事输入后，先生成全局设定和章节计划，再进入剧本生成。

### Toonflow
- 参考点：故事到动画短剧的剧本、分镜、角色资产、视频资产流水线。
- 落地方式：已新增自有实现 `createCharacterConsistencyPlan`，并与现有项目生产台的角色参考图/分镜图顺序一致。
- 当前输出：角色锚点提示词、负面提示词、seed、必需视图、固定特征、漂移风险、衍生资产规则。
- 后续接入：角色参考图生成前先生成一致性计划，分镜图只引用角色资产，不重复发明外观。

### sub2api
- 参考点：统一模型入口、账号池、路由策略、计费记录、后台模型健康检查。
- 落地方式：已新增自有实现 `createRelayGatewayPolicy` 和后台“网关策略预览”。
- 当前输出：兼容入口、路由模式、账号池策略、积分计费单位、供应商路由权重、健康状态。
- 后续接入：扩展 `/v1/chat/completions`、`/v1/images`、`/v1/videos` 兼容入口，把自己订阅账号作为服务端账号池统一调度。
