# 内容创作到漫剧制作闭环

## 产品定位

内容创作负责把灵感、参考作品或小说加工为可生产的剧本与实体；漫剧创作负责资产、镜头、画面、视频和导出。两个模块通过一次结构化交接连接，不要求用户再次粘贴内容或重复填写设定。

## 主流程

1. 创建内容项目：同类创作、原创故事、小说改编。
2. 内容加工：素材、分析、策略、大纲、正文、剧本、实体。
3. 交接检查：检查剧本、角色、场景、题材、风格，不增加独立确认页面。
4. 进入漫剧创作：写入本地交接草稿，打开新建漫剧并自动预填。
5. 漫剧生产：创作设定、镜头计划、角色与场景资产、首帧、视频、导出。

## 前端交接字段

- `title`：内容项目标题。
- `sourceType`：交接时统一为 `script`，避免已生成剧本再次走小说转换。
- `content`：最终剧本；暂未生成时使用当前已保存素材并明确标记。
- `genre`：内容策略中的题材。
- `artStyle`：内容项目风格档案名称。
- `contentProjectId`：记录来源内容项目，供后续回跳和同步。

## 交互原则

- 只有内容非空时允许进入漫剧创作。
- 按钮名称直接表达结果：`进入漫剧创作`。
- 无剧本时提示将使用当前素材，不伪造已生成结果。
- 模型路由不在内容创作页面重复展示。
- 评分用于提示优化方向，不阻止用户继续生产。
