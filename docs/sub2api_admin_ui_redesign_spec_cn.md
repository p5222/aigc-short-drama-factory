# Sub2API 风格后台 UI 改造规范

更新日期：2026-07-04

## 目标

这份文档用于指导“漫角”后台从简陋管理页升级为成熟 SaaS 运营后台。参考对象是开源项目 Wei-Shaw/sub2api 的后台信息架构与视觉语言，但不复制业务代码；我们吸收的是后台设计方法：稳定布局、清晰筛选、统一表格、状态标签、批量操作、可追踪的数据闭环。

## Sub2API 后台优势

1. 布局稳定：左侧固定导航，右侧业务区，顶部全局栏承载语言、通知、余额和账号。用户进入任意页面都知道“我在哪、我能做什么、怎么返回”。
2. 信息分层清楚：页面标题负责业务解释，工具栏负责搜索筛选和主操作，表格负责批量管理，分页区负责结果范围。
3. 色彩克制：浅灰/浅青页面底色，白色内容卡片，青绿色作为主操作色，蓝/绿/黄/红只承担状态意义。
4. 表格成熟：搜索框、筛选下拉、刷新、导出、新增、批量选择、单行操作、分页都有固定位置。
5. 状态轻量：启用、停用、已使用、余额、管理员等状态都使用小圆角标签，不抢主内容。
6. 适合高频运营：页面不是营销风，而是面向管理员反复查找、筛选、编辑、导出和追踪。

## 我的后台现状问题

当前后台功能已经具备，但视觉和交互还不够产品化：导航模块平铺、页面层级弱、表格和卡片规范不统一、按钮大小和状态标签风格不一致、部分页面显得拥挤。价格表尤其容易被灰色大块淹没，用户无法快速区分渠道、模型类型、计费单位和积分。

## 设计规范

### 布局

- 后台使用左右分栏：侧边栏 280-318px，主内容自适应。
- 侧边栏按业务分组：核心运营、商业化、模型与生产。
- 顶部栏固定 64-78px，放全局状态，不承载页面内筛选。
- 主内容间距 24-40px，模块之间保持 18-30px 间隔。

### 色彩

- 页面底色：`#f5f8fb` / `#effbfb`。
- 卡片底色：`#ffffff`。
- 主色：青绿色 `#0fa99c`，用于主按钮、选中态、余额/启用状态。
- 文本主色：`#101828`。
- 次级文本：`#667085` / `#718096`。
- 边框：`#e4ebf2` / `#dbe4ee`。
- 状态色：启用绿、停用灰、警告黄、危险红、信息蓝；不得把整页做成单一深色或大面积灰色。

### 圆角与间距

- 页面卡片：16-22px。
- 表格容器：16-22px。
- 输入框/按钮：10-14px。
- 标签：999px 或 7-10px。
- 表格行高：56-76px，后台编辑行可稍高，但不能像大灰块。

### 字体

- 字体族：Inter / system-ui / Microsoft YaHei。
- 页面标题：26-28px。
- 卡片标题：18-20px。
- 表格正文：13-14px。
- 标签：12-13px，字重 800-900。

### 按钮

- 主按钮：青绿色实心，带图标，用于新增、生成、保存、关键动作。
- 次按钮：白底灰边，用于刷新、导出、收起、批量修改。
- 危险按钮：红色弱底，用于删除和停用。
- 图标按钮：固定 40-42px，避免文字按钮挤压表格。

### 表格

- 表头使用浅底色和较强字重。
- 单元格内容要截断，不允许长模型名把布局撑坏。
- 表格顶部必须有搜索/筛选区。
- 有批量行为时要有多选框和批量操作区。
- 空状态必须写清楚“为什么空”和“下一步做什么”。

## 分页面改造方案

### 侧边导航

按业务分组：

- 核心运营：运营总览、用户管理、用户反馈、评测闭环。
- 商业化：兑换码、套餐会员、订阅会员。
- 模型与生产：模型路由、价格策略、提示词评分。

后续可以继续补折叠功能和当前菜单高亮。高亮规则跟随 hash 或路由。

### 首页仪表盘

首页不做大段说明，直接看关键经营指标：

- 注册用户、项目数量、任务成功率、启用渠道。
- 积分消耗、供应商成本、毛利估算、退款积分。
- 阶段成本与模型毛利风险用于运营判断。

### 用户管理

按 Sub2API 的用户管理思路保留：

- 顶部搜索用户、邮箱、手机号。
- 角色和状态筛选。
- 用户身份、积分余额、累计充值、累计消耗、密码重置、积分调整放在同一行。
- 后续增强 API Key、最近活跃时间、余额流水弹窗。

### 兑换码

兑换码页面采用“批次卡片 + 展开明细”更适合当前项目：

- 顶部指标：兑换码总数、启用中、已兑换次数、平均额度。
- 工具栏：搜索、状态筛选、批量启用/停用/删除未使用。
- 明细行：兑换码、活动名、积分、次数、有效期、状态、操作。
- 后续补导出 CSV 和批量修改弹窗。

### 模型路由

模型路由是后台技术运营核心：

- 按文本、生图、视频、配音、向量筛选。
- 每个供应商用卡片呈现，展示模型池、启用状态、成本提示和测试结果。
- API Key 只允许写入，不在前端明文显示。
- 插件能力用“已配置 / 缺少 Key / 停用”标签表达。

### 价格策略

价格策略同时服务后台运营和前台用户：

- 后台页：显示策略总数、启用策略、平均积分、成本合计。
- 按供应商分组，支持展开编辑。
- 模型类型使用不同色标签：文本蓝、生图绿、视频紫、配音橙、向量灰。
- 单行编辑只保留积分、成本、启停、保存、删除，避免表格过重。
- 前台价格表只展示启用策略，不显示供应商成本。

### 提示词评分

提示词评分页面定位为质量闭环后台：

- 左侧阶段列表，右侧模板编辑。
- 明确启用版本、评分维度、建议动作和 JSON 输出约束。
- 后续与评测记录联动，保留 promptVersion。

### 弹窗

弹窗用于低频、需要确认的操作：

- 新增用户、生成兑换码、批量修改、导出设置、删除确认。
- 弹窗宽度 520-760px；复杂表单可 880px。
- 底部固定取消/确认按钮，确认按钮必须写清楚动作。

## 本轮已落地

- 侧边栏改为后台分组菜单。
- 前台模型价格表改为浅色专业表格，增加渠道/模型/平均积分摘要。
- 后台价格策略增加指标摘要、类型色标签、单位标签、供应商图标和更清晰的分组行。
- Sub2API 源码仅保存在本地 `.agents/sub2api-reference` 作为设计参考，不进入 GitHub。
