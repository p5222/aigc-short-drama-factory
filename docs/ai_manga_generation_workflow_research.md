# AI 漫剧生成工作流调研与落地设计

## 调研依据

- LTX Studio 的故事板逻辑是从脚本出发，把脚本拆成场景和镜头，再为每个镜头生成静帧；镜头可单独编辑，脚本保留在镜头旁，复用角色/道具会作为元素跨镜头使用。参考：[LTX Studio Storyboard](https://ltx.io/blog/how-to-storyboard)。
- Runway Gen-4 References 强调用一张或多张参考图生成一致的角色、场景和物体，这说明角色一致性不能只靠文字提示词。参考：[Runway Gen-4 Image References](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References)。
- Google Flow 支持通过文本、ingredients、frames 和已有视频创建/编辑镜头，并允许带入已有素材创建角色或用 Imagen 创建素材。参考：[Google Flow Help](https://support.google.com/flow/answer/16353334) 与 [Google Flow Blog](https://blog.google/innovation-and-ai/products/google-flow-veo-ai-filmmaking-tool/)。
- Toonflow 的公开说明是“小说/剧本 -> AI 编剧 -> 智能分镜 -> 角色与视频生成”，并把脚本、角色、分镜、素材和视频节点放在生产工作台。参考：[Toonflow GitHub](https://github.com/HBAI-Ltd/Toonflow-app)。

## 推荐主流程

1. 剧本确认
   - 输入：故事原文、题材、画风、比例、集数、目标时长。
   - 输出：剧情梗概、全局设定、场景段落、角色卡、台词/旁白。
   - 用户动作：预览和确认剧本是否成立，不在这里调镜头参数。

2. 角色资产定稿
   - 输入：角色卡、用户上传/登记的正面参考图 URL、角色提示词、负面词、seed。
   - 输出：角色主参考图、多视图角色设定表、表情/服装色卡。
   - 用户动作：先锁定角色身份，再进入分镜。角色未定稿时不建议批量生分镜图。

3. 分镜拆解
   - 输入：已确认剧本、已定稿角色资产、场景资产。
   - 输出：镜头清单、画面描述、出场角色、台词、旁白、图片提示词、视频提示词。
   - 用户动作：检查镜头顺序、画面描述、角色是否正确。景别、视角、运镜、站位、音效放入高级参数。

4. 分镜图质检
   - 输入：分镜清单、角色/场景参考图、图片提示词。
   - 输出：每个镜头的首帧/分镜图。
   - 用户动作：看缩略图，单张重生或通过，不作为大图画廊。

5. 图生视频与时间线
   - 输入：分镜图首帧、视频提示词、时长、比例。
   - 输出：镜头视频片段。
   - 用户动作：检查动作是否符合镜头意图，失败时回到单镜头重生。

6. 配音、字幕、合成导出
   - 输入：台词/旁白、视频片段、字幕样式、导出格式。
   - 输出：TTS 清单、字幕文件、FFmpeg 合成包、最终成片。

## 当前项目落地

- 工作台新增“剧本确认”作为默认模块，避免用户直接进入镜头参数表。
- “角色定稿”支持粘贴角色正面参考图 URL 并保存为角色主参考资产。
- 角色参考图生成从“单张正面图”改为“多视图角色设定表”，包含正面、3/4侧面、侧面、背面、表情和服装色卡。
- 分镜图批量生成与单镜头重生都会根据镜头 `referenceAssetIds` 查找角色/场景参考图，并把参考图 URL 传入生图调用参数。
- “分镜拆解”只展示普通用户必须改的字段；专业镜头参数折叠到“高级镜头参数”。
- “分镜图质检画廊”改为缩略图质检，不再把大图撑满页面。
- “生产清单/分镜表”定位为导出和核对清单，不是主创作入口。

## 后续优化

- 接入对象存储上传控件，把本地图片上传后自动写入角色主参考 URL。
- 为多视图资产增加真正的“正面/侧面/背面/表情”结构化字段，避免只靠 `role_derivative` 命名约定。
- 支持每个镜头显式选择引用哪些角色、场景和道具资产。
- 增加角色一致性评分：脸型、发型、服装主色、道具是否漂移。
- 对支持参考图的上游模型分别实现真实 image-to-image 参数；不支持参考图的模型仅作为文字增强，不作为高一致性首选。
