# 漫角前后台视觉重构

本轮按照用户指定的 Wei-Shaw/sub2api 后台风格重构运营控制台，并细化创作者工作空间。实现保留现有业务接口、草稿保护、权限检查和表单流程。

## 参考依据

- [Sub2API 仓库](https://github.com/Wei-Shaw/sub2api)
- [侧栏结构](https://github.com/Wei-Shaw/sub2api/blob/main/frontend/src/components/layout/AppSidebar.vue)：256px 完整侧栏、收起模式、独立滚动导航、底部控制区。
- [样式系统](https://github.com/Wei-Shaw/sub2api/blob/main/frontend/src/style.css)：浅灰画布、白色圆角卡片、筛选工具栏、清晰表头、轻量状态标签。
- [官方主题](https://github.com/Wei-Shaw/sub2api/blob/main/frontend/tailwind.config.js)：青绿主色和蓝灰中性色。漫角主操作使用较深的青绿，保证小字号白字的可读性。

参考其视觉语言与版式比例，组件和业务代码由本项目实现，没有引入 Sub2API 的业务代码或依赖。

## 后台变化

256px 侧栏与 64px 顶栏统一全部管理模块；收起后仍可访问全部菜单，偏好保存在浏览器中，手机使用完整导航抽屉。底部展示当前管理员身份。

经营指标由相连的小格重构为独立数据卡；长状态文案采用较小字号。表格、筛选栏、分类切换、分页、行内编辑、详情抽屉、新增弹窗采用统一的边框、间距与圆角。

覆盖运营总览、用户、公告、工单、作品审核、创作质量、兑换码、充值套餐、订阅配置、模型路由、价格策略、提示词与操作记录。后台登录页同步采用浅色控制台风格。

## 创作端变化

暖白画布与青绿主色搭配更舒展的标题、细边框表面和明确的主要操作。统一工作台、作品库、生成队列、账户、充值、积分明细、帮助、设置、创作入口及表单。

已有项目的工作台增加“继续上次创作”，显示最近项目、更新时间与下一步动作，并进入对应项目；空账户保留四阶段创作引导。作品列表采用序号、作品信息、状态与下一步操作的稳定层级。

公开首页优化文字、导航和创作按钮；登录弹窗统一输入框与焦点样式。生产台沿用同一主题色与圆角。

## 验证与边界

- 本地完整浏览器回归 24/24 通过；登录输入框最终修正后，桌面和手机登录交互复验 2/2 通过。
- 桌面 1440×900、手机约 393×851：管理模块、创作页面、生产阶段、深浅主题均检查文档溢出和运行错误。
- 浏览器验证用户创建、修改、删除、恢复，搜索、分页、读取失败重试、离线提示、侧栏偏好与手机焦点恢复、继续创作、密码显示与弹窗焦点恢复。
- 有数据的后台和工作台另作视觉验证；后台标题、选中导航、主按钮等抽样文字对比度最低约 4.98:1。该结果仅代表抽样元素，不等同于全站无障碍认证。
- 浏览器中的示例账号、经营数据与作品仅由本地请求拦截提供，不写入生产数据库。
- 此轮为 UI 重构，真实支付和供应商生成接口的联调范围不变。

实现入口：`console-design.css`、`studio-design.css`、`public-design.css` 在应用启动时按固定顺序加载，分别管理后台、创作端和公开入口；避免路由按需加载改变视觉覆盖顺序。
