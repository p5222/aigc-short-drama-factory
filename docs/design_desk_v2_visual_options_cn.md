# 设计总台 V2 三套视觉方向

更新日期：2026-07-07

本轮没有改线上前端，只产出可评审的静态方向稿。预览文件位于 `docs/design-previews/`。

## 方向 A：剧本解析确认台

文件：`docs/design-previews/design-desk-v2-concept-a.png`

定位：

- 用来替换当前“剧本分场工作台”的轻量确认页。
- 重点是把剧本解析成场次、角色、地点、动作目标、台词和风险。
- 适合做生产前确认，不适合作为最终主工作台。

优点：

- 比当前 V1 更整齐，左中右高低更一致。
- 解析字段更像结构化数据，不像散落的小 UI。
- 右侧 inspector 有明确用途。

缺点：

- 仍然偏文本，视觉生产感不够强。
- 只能解决“剧本解析页难看”的问题，不能解决“整体生产总台”的问题。

## 方向 B：设计总台

文件：`docs/design-previews/design-desk-v2-concept-b.png`

定位：

- 推荐主方向。
- 剧本解析后进入的核心生产工作台。
- 用故事板矩阵把角色、场景、分镜图、视频、字幕、配音状态串起来。

优点：

- 首屏视觉最饱满，中间有明确主画布。
- 左侧是场景组，中心是镜头卡矩阵，右侧是镜头 inspector，底部是时间线。
- 很适合后续挂接角色精修、场景精修、单镜头导演台、分镜图重生成。
- 最符合“剧本分场之后就是设计总台”的产品逻辑。

缺点：

- 前端实现量比 A 大。
- 需要更清晰的数据映射：场景组、镜头状态、资产依赖、风险状态。

## 方向 C：视频闭环导演总控台

文件：`docs/design-previews/design-desk-v2-concept-c.png`

定位：

- 后期视频生成、字幕、配音、封面、导出的闭环工作台。
- 不建议作为剧本解析后的第一屏，而适合作为最终阶段总台。

优点：

- 视频闭环感强。
- 大预览 + 时间线 + 导出检查清单比较适合成片阶段。
- 适合后续导出可发布视频按钮和发布前检查。

缺点：

- 对当前“剧本拆解奇怪”的问题帮助不如 B。
- 需要依赖视频、字幕、配音数据成熟后再重点做。

## 推荐路线

建议采用组合：

```text
A 做轻量剧本解析确认页
B 做主设计总台
C 留作视频闭环阶段
```

下一步优先实现 B 的信息架构和视觉骨架，再把 A 作为进入 B 之前的确认层。

如果只选一个方向先推进，选 B。
