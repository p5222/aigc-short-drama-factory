# 漫角：用户端与运营后台迭代说明

日期：2026-10-23。基线：`b2d2ea2`。范围：现有仓库本地迭代，未发布到服务器。

## 代码理解与架构

本仓库是 pnpm monorepo。`apps/web` 使用 React 19、TypeScript、Vite；用户端和 `/admin` 共享登录、请求、语义主题与弹层基础设施，通过页面组件分开业务。`apps/api` 使用 Express、Prisma/PostgreSQL、Redis/BullMQ，实现认证、内容版本、生成任务、积分、导出、审核、工单与审计。`packages/shared` 提供业务类型和媒体/分集规则，必须先构建才能供新检出的应用使用。

用户导航由 `useCreatorNavigation` 管理 hash 路由；后台由 `adminNavigation` 管理已接受导航，保留未保存草稿确认。生产区用 reducer 管理阶段、镜头选择和检查器。数据库是业务事实来源，不能从浏览器显示结果推断支付、供应商生成或持久化成功。

| 用户框架 | `components/Shell.tsx`：导航、作品搜索、手机抽屉、主题与账户入口 |

## 用户端完整流程与功能边界

| 步骤 | 页面与操作 | 成功结果 | 必须保留的异常处理 |
| --- | --- | --- | --- |
| 进入与认证 | 公开页、登录、注册、恢复会话 | 进入自己的工作台 | 失效登录重新认证；网络故障允许重试；旧请求不得清除新会话 |
| 故事起点 | 工作台“内容创作”或“新建漫剧” | 进入写作或导入原稿 | 空账户有四阶段指引；有作品时优先呈现最近作品 |
| 内容发展 | 来源→分析→大纲→章节→剧本 | 保存版本并进入生产 | 失败保留输入；版本与确认状态不能被轮询覆盖 |
| 创建与报价 | 导入小说/剧本，确认模型、比例、范围与费用 | 创建项目与生成任务 | 内容校验、缺模型/价格、余额不足、重复提交及超时结果待核对 |
| 内容确认 | 生产区“内容” | 确认剧本和分镜资料 | 有修改先保存；离开确认，取消则保留草稿 |
| 资产准备 | 角色、场景、道具和参考图 | 建立可复用素材与引用 | 缺素材显示原因；生成前明确成本；上传和生成失败可恢复 |
| 镜头制作 | 分镜脚本、首帧、视频 | 镜头与图片/视频资产关联 | 单镜头状态独立；任务失败可查原因；不能把占位内容当完成 |
| 任务追踪 | 生成队列，按状态/类型/关键词筛选 | 看到真实进度与结果，返回项目 | 每页20条；筛选回第一页；明细跟随当前页；操作中禁重复提交 |
| 成片与交付 | 配音、字幕、时间线、导出报价与下载 | 获得实际导出文件 | 未满足导出条件说明原因；不可播放资源不能冒充完成 |
| 展示发布 | 提交成片审核→后台批准/驳回 | 审核通过后进入公开展示 | 发布状态、驳回原因和重新提交均以服务端返回为准 |
| 账户与售后 | 资料、安全、卡密兑换、积分流水、帮助与工单 | 余额/流水可核对，问题可追踪 | 兑换失败不清空上下文；消费与冻结分开；工单反馈与回复留痕 |

当前充值页面采用“店铺购买卡密→回平台兑换”。服务端存在订单与 mock 回调代码，但不能将其作为真实支付网关已接入的证明。会员订阅购买、自动月度发放和权益结算仍未开放，继续保留明确的未开放标识。

## 后台管理完整流程与功能细节

| 模块 | 运营工作 | 检查要点 |
| --- | --- | --- |
| 运营总览 | 查看用户、项目、任务、实收、消耗和模型配置，直接进入处理模块 | 成本未知显示待对账；模型或价格读取失败不能显示0 |
| 用户管理 | 搜索、角色/状态筛选、分页、创建、停启、积分调整、密码重置 | 当前页与全量指标区分；批量操作和积分入账留痕；保护当前草稿 |
| 操作记录 | 按操作、目标、操作人和结果筛选 | “结果待核对”不显示成功；可追溯请求与目标 |
| 平台公告 | 公告和帮助文章，置顶、排期、启停、内容编辑 | 实际生效时间、状态、保存反馈清楚 |
| 支持工单 | 查看问题、上下文、站内回复与处理状态 | 空工单、加载失败、长对话、回复中和并发状态需要分别处理 |
| 创作现场管理 | 审核作品、修改展示信息、精选和顺序 | 预览真实媒体；保存草稿与批准发布区分 |
| 创作质量中心 | 信号、反馈、数据集、实验、模型成本、优化回流 | 缺评分/样本/耗时不显示虚构指标；快照失败可刷新 |
| 兑换码 | 生成唯一卡密，配置积分、次数及启停 | 额度和可用性明确，注意兑换和人工入账不能重复 |
| 充值套餐 | 配置一次性充值包、售价与购买链接 | 以已保存配置为准，不虚构在线支付成功 |
| 订阅会员 | 预留方案管理 | 购买及自动权益未开放，避免误售 |
| 模型路由 | 供应商、模型池、能力、启停与连接测试 | 测试当前已保存配置；失败原因可见，凭证不回显 |
| 价格策略 | 按渠道、模型、计费单位配置积分及成本 | 明确单位；生成报价与实际结算分开核对 |
| 提示词评分 | 阶段提示词、评分标准与输出约束 | 版本、启用状态、JSON约束和保存反馈清楚 |

日常运营顺序：总览定位问题→对应用户/工单/模型/价格模块处理→查看操作记录→回用户端核对实际结果。商业化配置顺序：配置并测试模型→配置计费→配置充值包或兑换码→验证余额/冻结/消耗/退还→开放服务。

## 本轮已实施

1. **用户体验**：工作台新增内容创作入口、全部作品入口及空账户四阶段说明；空账户取消三块无意义零值摘要；紧凑最近任务空态。有作品的账户仍优先看到待处理与项目。
2. **任务规模**：任务列表改为20条一页，保留全量筛选；翻页/筛选后明细选中项限制在当前页；手机分页按钮44px。
3. **后台定位**：侧栏支持模块搜索、无结果清空和手机输入焦点循环；顶栏展示所属分组和当前模块；增加跳到内容链接。
4. **后台操作闭环**：总览增加模型、价格、工单和审计快捷入口；能力名称中文化；表格区域支持键盘聚焦和横向滚动。
5. **主题修复**：修复深色运营说明卡、刷新按钮和复合搜索内框；继续使用现有语义变量。
6. **请求可靠性**：读请求30秒、写请求180秒上限（包含读取响应体）；主动取消保留取消语义；写操作超时/断网提示先核对结果，绝不自动重放；处理Headers实例及无效JSON；代理HTML不直出到页面。
7. **会话与资源**：只有当前凭证对应的401才触发退出；总览必须读到模型与价格；后台错误边界随模块变化恢复；全局增加离线提醒。
8. **加载与开发**：登录、作品、任务、剪辑、账户/帮助与积分页面按需加载；根级错误边界保护入口；开发、检查、测试前自动构建共享包。
9. **回归资产**：增加请求层边界测试和浏览器工作流测试，支持本机Chrome路径与外置测试输出目录。测试夹具不进入业务代码。
10. **生产与审核**：空项目不再将资产阶段误标完成；成片无镜头时明确先创建分镜，并提供返回分镜按钮；审核列表重试清除旧错误，末页数据变化后回到有效页。

浏览器检查使用显式的接口夹具，覆盖正常空态、首次读取失败恢复、41条任务分页/筛选、模块搜索、浅/深主题布局、内容入口、生产四阶段和断网恢复。后台质量快照采用503失败夹具，其证据为错误恢复入口，而非真实质量数据成功展示。页面截图只作为当前版本渲染证据，不宣称是与旧版本同状态的视觉对照。

以下是明确的上线缺口，不能用UI检查替代：

- 本机没有启动真实 PostgreSQL/Redis 服务；持久化、权限隔离、队列恢复和数据库相关测试需在隔离服务中继续执行。
- 真实模型凭证、充值支付/店铺流程、TTS与FFmpeg运行环境没有进行本次真实联调；涉及付费和真实发布需要相应环境与账号。
- 订阅自动发放、折扣/优先队列与真实支付网关需要独立实现及验收，不作为本轮已完成能力。
- 遗留 `styles.css` 约649KB、`AdminPage.tsx` 约320KB，已减少入口加载压力，但仍需分模块迁移样式和组件。没有直接删除大段旧样式，避免生产工作区回归。
- 空数据与失败状态浏览器检查不能覆盖所有真实长内容、复杂时间线、媒体慢加载和账号权限组合。
- 尚未合并、推送或部署；正式上线前应进行数据库备份/恢复演练、真实环境验收与灰度回滚检查。
