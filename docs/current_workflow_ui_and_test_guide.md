  - 前台保留循环视频背景，品牌为“漫角”，左侧内容扩大到约 45%。

## 3. 推荐前台测试流程

1. 登录前台。
2. 进入“新建漫剧”。
3. 输入故事或样例故事。
4. 选择文本模型：低成本用 DeepSeek，高质量可选 ZML `gpt-5.5`。
5. 选择生图模型：低成本用通义 Qwen Image，高质量可选 ZML `gpt-image-2`。
6. 生成核心剧情、剧本和角色卡。
7. 进入项目生产台。
8. 按顺序执行：
   - 角色定稿
   - 镜头编辑
   - 分镜预览
   - 视频导出
   - 分镜表核对
9. 在“分镜预览”检查每个镜头是否真实出现图片。
10. 如需清理旧测试作品，只保留最新作品，可调用 `POST /api/projects/prune-to-latest`，后续建议在后台加可视化按钮。

## 4. 分镜工作台正确工作流

当前工作台不应再理解为“很多功能堆在一起”，而是一个按生产依赖推进的流水线。

### 4.1 角色定稿

目标：先锁定角色脸、发型、服装主色、配饰、负面提示词和 seed。

为什么重要：角色不稳定时，后续分镜图和视频都会漂移，继续生成没有生产意义。

UI 操作：

- 左侧展示角色卡信息：姓名、身份、外貌、服装、性格、seed、负面提示词。
- 右侧展示角色参考图。
- 没有参考图时，主按钮为“生成角色参考图”。
- 每个角色需要显示状态：未生成、生成中、已定稿、失败。
- 后续优化：支持“重生本角色”“锁定为最终角色”“上传参考图”“替换 seed”。

### 4.2 镜头编辑

目标：把剧本拆成真正可生产的镜头，而不是只看一张分镜表。

UI 操作：

- 左侧：镜头列表，显示镜头号、景别、时长和简短画面描述。
- 中间：当前镜头预览图，没有图时显示待生成画面。
- 右侧：镜头导演台，可编辑时长、景别、视角、运镜、角色、场景、站位、朝向、动作、情绪、台词、旁白、音效、图片提示词、视频提示词。
- 保存镜头后，当前镜头关联的旧图和旧视频应标记为需要重生成。

后续优化：

- 增加“镜头复制”“镜头插入”“镜头删除”“镜头上移/下移”。
- 增加提示词质量检查：是否缺角色、是否缺站位、是否有字幕水印、是否与角色设定冲突。

### 4.3 分镜预览

目标：这是质检画廊，不是最终分镜表。

它的意义：

- 快速看每个镜头是否真的生成图片。
- 检查比例、角色脸、服装、站位、情绪是否符合镜头描述。
- 对失败或不满意的单镜头进行重生。

UI 操作：

- 按镜头顺序展示图片卡片。
- 每张卡片显示镜头号、状态、景别、运镜、描述。
- 每张图提供“重生本图”。
- 没有图时显示“生成本图”，不再假装完成。

### 4.4 视频导出

目标：基于已确认的分镜图，进入图生视频、TTS、字幕、合成导出。

当前状态：

- 已有视频任务入口和导出任务骨架。
- TTS、字幕、FFmpeg 合成导出已有接口雏形。
- 真实视频模型仍需继续做完整异步任务轮询和文件落地。

后续优化：

- 每个镜头显示首帧、视频状态、时长、运镜提示词。
- 支持单镜头重生视频。
- 支持 TTS 配音清单、字幕 SRT、合成包导出。

### 4.5 分镜表

目标：分镜表是生产清单和对账表，不是主要视觉预览区。

它的意义：

- 给编剧、导演、剪辑、配音和运营核对字段。
- 导出 JSON 后可给外部工具、Excel 或后续批处理使用。
- 记录镜头号、时长、景别、运镜、角色、画面、台词、旁白、音效、图片提示词、视频提示词和资产引用。

后续优化：

- 表格行内编辑。
- 导出 Excel。
- 增加“资产是否齐全”“提示词是否合格”“是否已生成视频”等列。

## 5. 后台管理系统模块逻辑

后台应保持浅色、高密度、分页面管理，不做长瀑布。

- 运营总览：用户数、项目数、任务成功率、积分消耗、模型成本、最近任务异常。
- 用户积分：查看用户、角色、状态、余额、冻结余额、累计充值、累计消耗；支持人工加减积分并写流水。
- 兑换码：批量生成不同兑换码，每个 code 独立记录、默认一次性使用；支持启停、额度、最大兑换次数。
- 套餐会员：配置充值包、会员包、赠送积分、折扣、启停；前台只显示启用项。
- 模型渠道：管理 provider、baseUrl、模型列表、启停；支持文本/生图/视频连接测试。
- 价格策略：按 provider + model + unit 配置积分单价和供应商成本；生成任务优先读取启用价格。
- 提示词模板：展示策划、编剧、分镜导演、角色一致性模板；后续扩展版本管理和灰度。
- 支付订单：创建充值订单、模拟或真实回调、支付记录、订单状态。
- 发票：用户提交发票申请，后台审核和记录。
- 系统运维：健康检查、队列重试、备份、对象存储、限流、日志监控。

## 7. 距离部署上线还差什么

- 真实支付：需要接入微信/支付宝商户、签名校验、幂等回调、退款和对账。
- 视频生成：豆包 Seedance、通义万相需要完成真实异步任务轮询、结果下载、本地/OSS 入库。
- TTS 和字幕：需要接入真实 TTS provider，生成音频和 SRT/VTT。
- FFmpeg 合成：需要生产环境安装 FFmpeg，并做任务队列化、失败重试和导出文件管理。
- 对象存储：本地 `storage` 已可用，生产建议换 OSS/S3/COS。
- 权限分级：后端已有角色雏形，后台 UI 还要按权限隐藏或禁用模块。
- 日志监控：需要接入可视化日志、告警和成本异常提醒。
- 备份：已有备份脚本基础，生产需加定时备份和恢复演练。
- 安全：密钥迁移到服务器环境变量或密钥管理服务；禁止把 `.env.local` 推送到 Git。
