漫角项目：合并之后如何发布？

本工具负责 GitHub 拉取与推送。服务器发布使用独立命令，需先配置当前设备的 SSH 公钥。

git switch main
git pull --ff-only origin main
pnpm deploy:server --check
pnpm deploy:server

查看项目内 docs/operations/github-and-multi-device-deployment.md。不要同时从两台电脑发布。

换电脑需要带走哪些东西？

复制整个 git-workbench 文件夹或下载便携包。新电脑安装 Git、Node.js 24、GitHub CLI，登录自己的账号后启动工具，再从 GitHub 克隆项目。项目 .env、生成素材、数据库和 SSH 私钥不会随代码自动同步。
