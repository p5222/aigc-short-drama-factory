    一个人，也可以有清楚的研发流程。

    1编辑器开发

    在本机或 Remote SSH 工作副本中，用 AI 和编辑器修改、测试。

    2GitHub 审查

    提交功能分支、推送 GitHub，在 PR 中核对差异并合并。

    3同步主线

    选对服务器项目，切回 main，拉取并核对版本。

    4发布与核验

    确认发布目标，查看日志，核验线上提交与预期一致。
